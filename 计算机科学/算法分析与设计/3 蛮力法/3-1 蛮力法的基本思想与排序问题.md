# 3.1 蛮力法的基本思想与排序问题

## 3.1.1 什么是蛮力法

**蛮力法是一种简单直接地解决问题的方法，常常直接基于问题的描述和所涉及的概念定义**。用一句话概括它的策略，就是“**just do it**”：把所有可能的情况都列出来，逐一检验；或者按照最直观的步骤，一步一步地做。

它的地位可以用三句话说明：

- **适应能力强**：几乎任何问题都能用蛮力法给出一个解；
- **容易实现**：不需要巧妙的洞察，代码通常很短；
- **可作为基准**：更高效的算法是否正确、到底快多少，都要拿蛮力法的结果来对照。

它的缺点同样明显：**效率通常很低**，因为“枚举所有可能”往往意味着指数级的时间。

### 例：百钱百鸡

> 鸡翁一，值钱五；鸡母一，值钱三；鸡雏三，值钱一。百钱买百鸡，问翁、母、雏各几何？

设公鸡 $x$ 只、母鸡 $y$ 只、小鸡 $z$ 只，则

$$\begin{cases}
x+y+z=100\\
5x+3y+\dfrac{z}{3}=100
\end{cases}$$

最直接的做法是三重循环枚举 $x,y,z$，复杂度 $O(n^3)$。稍作代数变形：第二式乘 $3$ 得 $15x+9y+z=300$，代入 $z=100-x-y$，得

$$14x+8y=200 \quad\Longrightarrow\quad 7x+4y=100$$

于是只需枚举 $x$，$y=(100-7x)/4$ 必须是非负整数。由 $y\ge0$ 得 $x\le14$，再由整除性得 $x\equiv0\pmod 4$。四个解为：

| 公鸡 $x$ | 母鸡 $y$ | 小鸡 $z$ |
| ---: | ---: | ---: |
| 0 | 25 | 75 |
| 4 | 18 | 78 |
| 8 | 11 | 81 |
| 12 | 4 | 84 |

::: tip 蛮力法也需要“动脑”
同样是蛮力，三重循环 $O(n^3)$ 与一重循环 $O(n)$ 的差别，来自**枚举前先做代数化简**。蛮力法的精髓不是“无脑穷举”，而是“**缩小需要枚举的候选集，同时保证不遗漏**”。
:::

## 3.1.2 选择排序

### 思想

首先扫描整个序列，找到最小元素，与第一个元素交换，把它“归位”；然后从第二个元素开始，在剩下的 $n-1$ 个元素中找最小，与第二个元素交换；如此进行 $n-1$ 遍，排序完成。

```plaintext
selectSort(A[0..n-1])
for i ← 0 to n-2
    min ← i
    for j ← i+1 to n-1
        if A[j] < A[min]
            min ← j
    swap A[i] and A[min]
```

### 正确性证明

用**循环不变式**：在第 $i$ 轮循环开始前，$A[0..i-1]$ 已经按升序排列，且其中元素恰好是原数组中最小的 $i$ 个元素。

- **初始化**：$i=0$ 时，前缀为空，命题真。
- **保持**：第 $i$ 轮在 $A[i..n-1]$ 中找到最小值 $A[\min]$，它与 $A[i]$ 交换后，$A[0..i]$ 成为最小的 $i+1$ 个元素且有序。
- **终止**：$i=n-1$ 时，前 $n-1$ 个元素已是最小的 $n-1$ 个且有序，最后一个元素自然是最大值，整个数组有序。

### 复杂度分析

比较次数与输入无关：

$$T(n)=\sum_{i=0}^{n-2}\sum_{j=i+1}^{n-1}1=\sum_{i=0}^{n-2}(n-1-i)=\frac{n(n-1)}{2}=\Theta(n^2)$$

交换次数至多 $n-1$ 次。空间 $O(1)$。

::: warning 选择排序不稳定
例如 $[2_a, 2_b, 1]$，第一轮把 $1$ 与 $2_a$ 交换，得到 $[1, 2_b, 2_a]$，两个 $2$ 的相对次序被破坏。若要求稳定排序，应选择冒泡、插入或归并。
:::

## 3.1.3 冒泡排序

### 思想

扫描整个序列，比较相邻元素，若逆序就交换。每扫描一遍，当前未排序部分的最大元素会像气泡一样“浮”到末尾。重复 $n-1$ 遍即可。

```plaintext
bubbleSort(A[0..n-1])
for i ← 0 to n-2
    for j ← 0 to n-2-i
        if A[j] > A[j+1]
            swap A[j] and A[j+1]
```

### 复杂度分析

第 $i$ 遍比较 $n-1-i$ 次，总比较次数

$$T(n)=\sum_{i=0}^{n-2}(n-1-i)=\frac{n(n-1)}{2}=\Theta(n^2)$$

最坏情况下交换次数也是 $\Theta(n^2)$（完全逆序时每次比较都交换）。

### 提前终止优化

如果某一遍扫描没有发生任何交换，说明序列已经有序，可以立即结束：

```plaintext
bubbleSort(A[0..n-1])
for i ← 0 to n-2
    swapped ← false
    for j ← 0 to n-2-i
        if A[j] > A[j+1]
            swap A[j] and A[j+1]
            swapped ← true
    if not swapped break
```

优化后**最好情况**（已有序）只需 $n-1$ 次比较，$T_{\min}(n)=\Theta(n)$；最坏与平均仍是 $\Theta(n^2)$。

## 3.1.4 三种平方级排序的比较

| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定性 | 特点 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 选择排序 | $\Theta(n^2)$ | $\Theta(n^2)$ | $\Theta(n^2)$ | $O(1)$ | 不稳定 | 交换次数最少（$\le n-1$） |
| 冒泡排序 | $\Theta(n)$（优化后） | $\Theta(n^2)$ | $\Theta(n^2)$ | $O(1)$ | 稳定 | 可提前终止，适合“几乎有序” |
| 插入排序 | $\Theta(n)$ | $\Theta(n^2)$ | $\Theta(n^2)$ | $O(1)$ | 稳定 | 小数组最快，常作为快排的底层 |

::: info 为什么还要学这些“慢”排序？
1. 它们是理解“比较排序”的起点，也是分析复杂度最好的练手材料；
2. 插入排序在小规模数据上常数极小，工业级排序库普遍在子数组长度小于 $16$ 时切换为插入排序；
3. 冒泡排序的“提前终止”思想，是自适应算法的雏形。
:::
