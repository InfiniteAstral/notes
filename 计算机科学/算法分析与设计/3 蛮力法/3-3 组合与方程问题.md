# 3.3 组合与方程问题

蛮力法最擅长的事情，是**把“所有可能性”变成“可执行的枚举”**。组合问题与方程问题正是它的主战场：前者的解空间是离散的集合，后者的解空间是连续的区间。

## 3.3.1 组合问题：枚举解空间

组合问题的解通常可以表示为一个向量 $(x_1,x_2,\dots,x_n)$，每个分量从一个有限集合中取值。所有可能取值的笛卡尔积，就是**解空间**。

| 问题 | 解向量 | 解空间大小 |
| :--- | :--- | :--- |
| 0-1 背包 | $x_i\in\{0,1\}$，表示第 $i$ 件物品是否装入 | $2^n$ |
| 子集问题 | 每个元素选或不选 | $2^n$ |
| 全排列 | $(x_1,\dots,x_n)$ 是 $1..n$ 的一个排列 | $n!$ |
| 旅行商问题（TSP） | 访问城市的顺序 | $(n-1)!/2$ |
| 分配问题 | 第 $i$ 个人做第 $x_i$ 项工作 | $n!$ |
| $m$ 着色 | $x_i\in\{1,\dots,m\}$ | $m^n$ |

### 枚举所有子集

用 $n$ 位二进制数表示一个子集，第 $i$ 位为 $1$ 表示选中第 $i$ 个元素：

```plaintext
for mask ← 0 to 2^n - 1
    for i ← 0 to n-1
        if mask 的第 i 位为 1
            输出 A[i]
```

外层 $2^n$ 次，内层 $n$ 次，总复杂度 $O(n2^n)$。

### 枚举所有排列

```plaintext
permute(A, k)
if k = n
    输出 A
else
    for i ← k to n-1
        swap A[k], A[i]
        permute(A, k+1)
        swap A[k], A[i]      // 恢复现场
```

共有 $n!$ 个叶子，每个叶子输出 $n$ 个元素，总复杂度 $O(n\cdot n!)$。

::: warning 枚举排列必须“恢复现场”
递归返回后，要把数组恢复成进入本层时的样子，否则后续分支会在被修改过的数组上继续，导致遗漏或重复。这是回溯法中最容易犯的错误之一。
:::

### 例：0-1 背包

> 有 $n$ 件物品，第 $i$ 件重 $w_i$、价值 $v_i$，背包容量 $C$。每件物品只能选或不选，求能装下的最大总价值。

蛮力法枚举所有 $2^n$ 个子集，对每个子集检查总重量是否超过 $C$，并记录最大价值：

```plaintext
best ← 0
for mask ← 0 to 2^n - 1
    w ← 0, v ← 0
    for i ← 0 to n-1
        if mask 的第 i 位为 1
            w ← w + w[i]; v ← v + v[i]
    if w ≤ C and v > best
        best ← v
```

复杂度 $O(n2^n)$。当 $n=30$ 时约为 $3\times10^{10}$ 次操作，已经无法接受；当 $n=50$ 时彻底不可行。

### 例：分配问题

> $n$ 个人、$n$ 项工作，第 $i$ 人做第 $j$ 项工作的成本为 $c_{ij}$。每项工作恰好由一人完成，求最小总成本。

枚举所有排列 $p$，计算 $\sum_i c_{i,p(i)}$，取最小。复杂度 $O(n\cdot n!)$。$n=10$ 时 $10!\approx3.6\times10^6$ 尚可，$n=15$ 时 $15!\approx1.3\times10^{12}$ 就无能为力了。

::: tip 从“枚举”到“搜索”
组合问题的解空间是一棵树：第 $1$ 层决定 $x_1$，第 $2$ 层决定 $x_2$……蛮力法相当于**遍历整棵树**。如果我们能在某个结点提前判断“这棵子树里不可能有更好的解”，就可以整枝剪掉——这就是**回溯法**与**分支限界法**的起点。第 7、8 章会详细展开。
:::

## 3.3.2 方程问题：连续区间的枚举

### 扫描法

求方程 $f(x)=0$ 在区间 $[a,b]$ 上的根，最朴素的方法是以很小的步长 $h$ 扫描：

```plaintext
for x ← a to b step h
    if f(x) = 0 return x
    if f(x) * f(x+h) < 0
        在 (x, x+h) 内有一个根
```

步长越小，越不容易漏根，但计算量越大。对于高次方程或剧烈振荡的函数，扫描法可能漏掉靠得很近的两个根。

### 二分法

若 $f$ 在 $[a,b]$ 上连续，且 $f(a)\cdot f(b)<0$，则区间内至少有一个根。每次取中点 $m=(a+b)/2$：

- 若 $f(m)=0$，找到根；
- 若 $f(a)\cdot f(m)<0$，根在 $[a,m]$；
- 否则根在 $[m,b]$。

```plaintext
bisection(f, a, b, ε)
while b - a > ε
    m ← (a + b) / 2
    if f(m) = 0 return m
    if f(a) * f(m) < 0 b ← m
    else a ← m
return (a + b) / 2
```

每次区间长度减半，经过 $k$ 次后误差为 $(b-a)/2^k$。要达到精度 $\varepsilon$，需要

$$k=\left\lceil\log_2\frac{b-a}{\varepsilon}\right\rceil$$

次迭代，时间复杂度 $O(\log(1/\varepsilon))$。

::: warning 二分法只保证“找到一个根”
若区间内有多个根，二分法只会收敛到其中一个；若 $f(a)\cdot f(b)>0$，区间内仍可能有偶数个根，二分法无法启动。因此实际使用前通常先扫描确定有根区间。
:::

### 其他数值方法

| 方法 | 思想 | 收敛速度 | 局限 |
| :--- | :--- | :--- | :--- |
| 二分法 | 不断缩小区间 | 线性（每步误差减半） | 需要变号区间 |
| 牛顿法 | 用切线逼近 | 二次（近根处） | 需要导数，可能发散 |
| 割线法 | 用割线代替切线 | 超线性 | 需要两个初值 |
| 不动点迭代 | $x_{k+1}=g(x_k)$ | 依赖压缩性 | 可能不收敛 |

这些方法属于“数值分析”的范畴，本课程关注的是其中的**算法思想**：用有限的、确定的步骤，把连续问题转化为可计算的离散过程。

## 3.3.3 蛮力法的总结

| 优点 | 缺点 |
| :--- | :--- |
| 思路简单，几乎适用于所有问题 | 时间复杂度往往是指数级 |
| 容易实现，正确性直观 | 无法处理大规模输入 |
| 可作为高效算法的正确性基准 | 常数因子也可能很大 |
| 是回溯、分支限界的直接基础 | 需要额外技巧来缩小枚举范围 |

::: tip 考试中的蛮力法
考试若要求“设计一个算法”，而你想不出更优策略，**写出正确的蛮力算法并分析复杂度，通常也能拿到大部分过程分**。若能在蛮力基础上指出“可以剪枝/可以预处理/可以换数据结构”，则是加分项。
:::
