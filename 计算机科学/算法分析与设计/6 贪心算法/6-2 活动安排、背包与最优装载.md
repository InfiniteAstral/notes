# 6.2 活动安排、背包与最优装载

## 6.2.1 活动安排问题（补充）

活动安排在 6.1 节已经给出了贪心策略与正确性证明，这里补充两个常考变体：

| 变体 | 贪心是否适用 | 正确做法 |
| :--- | :--- | :--- |
| 最大化相容活动个数 | 是 | 按结束时间排序，贪心 |
| 每个活动带权，最大化总权值 | 否 | 动态规划（带权区间调度） |
| 用最少的教室安排所有活动 | 是 | 按开始时间排序，用最小堆维护教室结束时间 |
| 区间覆盖（用最少点覆盖所有区间） | 是 | 按右端点排序，每次在右端点放点 |

::: tip 带权活动安排为什么不能贪心
若每个活动有权值 $w_i$，目标是最大化 $\sum w_i$，则“结束最早”可能选了一个权值很小的活动，挡住后面两个高权值活动。正确做法是 DP：

$$dp[i]=\max\{dp[i-1],\ dp[p(i)]+w_i\}$$

其中 $p(i)$ 是最后一个与 $i$ 相容的活动。这是“贪心失效、DP 接管”的典型例子。
:::

## 6.2.2 分数背包问题

### 问题

有 $n$ 件物品，第 $i$ 件重 $w_i$、价值 $v_i$，背包容量为 $c$。与 0-1 背包不同，物品**可以分割**，允许装入一件物品的一部分。求最大总价值。

### 贪心策略

按**单位重量价值** $v_i/w_i$ 从大到小排序，依次装入：

- 若剩余容量足够，装入整件；
- 若不够，装入剩余容量对应的部分，然后结束。

```text
fractionalKnapsack(w, v, c, n)
按 v[i]/w[i] 降序排序
total ← 0
for i ← 1 to n
    if c ≥ w[i]
        total ← total + v[i]
        c ← c - w[i]
    else
        total ← total + v[i] * c / w[i]
        break
return total
```

时间复杂度 $O(n\log n)$（排序），空间 $O(1)$。

### 正确性（交换论证）

::: details 证明
设物品已按 $v_1/w_1\ge v_2/w_2\ge\cdots\ge v_n/w_n$ 排序。考虑任意最优解，若它没有优先装物品 $1$，而是装了某个单位价值更低的物品 $j$ 的 $x$ 单位重量，则把这份重量换成物品 $1$（若物品 $1$ 还有剩余）不会降低总价值：

$$\frac{v_1}{w_1}\ge\frac{v_j}{w_j}\quad\Longrightarrow\quad x\cdot\frac{v_1}{w_1}\ge x\cdot\frac{v_j}{w_j}$$

反复交换，可把最优解变成“优先装满单位价值最高的物品”的形式，即贪心解。故贪心最优。
:::

### 分数背包 vs 0-1 背包

| 维度 | 分数背包 | 0-1 背包 |
| :--- | :--- | :--- |
| 物品可分割 | 是 | 否 |
| 贪心是否最优 | 是 | 否 |
| 最优算法 | 按单位价值排序 | 动态规划/分支限界 |
| 时间复杂度 | $O(n\log n)$ | $O(nc)$ 伪多项式 |
| 解的形式 | 实数向量 | 0-1 向量 |

::: info 分数背包的贪心解是 0-1 背包的上界
把 0-1 背包松弛为“允许分割”，得到的最优值一定不小于原问题的最优值。因此分数背包的贪心结果常被用作分支限界法的**上界函数**：若当前结点的上界都不如已知最优解，就可以剪枝。
:::

## 6.2.3 最优装载问题

### 问题

有 $n$ 个集装箱要装上一艘载重量为 $c$ 的轮船，第 $i$ 个集装箱的重量为 $w_i$。在装载体积不受限制的情况下，如何装入尽可能多的集装箱？

### 贪心策略

**优先选最轻的集装箱**：按重量升序排序，依次装入，直到装不下为止。

```text
optimalLoading(w, c, n)
按 w 升序排序
count ← 0
for i ← 1 to n
    if w[i] ≤ c
        c ← c - w[i]
        count ← count + 1
    else break
return count
```

时间复杂度 $O(n\log n)$。

### 正确性

::: details 交换论证
设最优解装了 $k$ 个集装箱，其重量从小到大为 $w_{i_1}\le w_{i_2}\le\cdots\le w_{i_k}$。贪心解装了 $g$ 个，重量为 $w_{j_1}\le\cdots\le w_{j_g}$。

由于贪心每次选当前最轻的，可以归纳证明 $w_{j_t}\le w_{i_t}$ 对所有 $t$ 成立。若 $g<k$，则贪心装完 $g$ 个后剩余容量已经小于下一个最轻的集装箱，而最优解却能装下 $k>g$ 个，这与“贪心每次选最轻”矛盾。因此 $g\ge k$，贪心最优。
:::

::: warning 最优装载 ≠ 0-1 背包
最优装载只关心“装多少个”，不关心价值；因此按重量贪心是对的。若每个集装箱还有价值，要求总价值最大，就变成了 0-1 背包，贪心失效。
:::

## 6.2.4 多机调度问题

### 问题

有 $n$ 个作业，$m$ 台相同的机器。作业 $i$ 的处理时间为 $p_i$，每个作业必须在一台机器上连续加工，不能拆分。求一个调度方案，使所有作业完成时间（最大完工时间，makespan）最小。

这是**NP 难**问题（$m\ge2$ 时），没有多项式精确算法。贪心给出的是一个近似算法。

### 贪心策略：最长处理时间优先（LPT）

按处理时间**从大到小**排序，依次把每个作业分配给**当前负载最小**的机器。

```text
LPT(p, n, m)
按 p 降序排序
用最小堆维护 m 台机器的当前负载，初始为 0
for i ← 1 to n
    取出负载最小的机器 k
    把作业 i 分配给机器 k
    机器 k 的负载 += p[i]
    将机器 k 放回堆
return 最大负载
```

时间复杂度 $O(n\log n + n\log m)$。

### 近似比

设 $C_{\max}$ 为 LPT 的完工时间，$C^*$ 为最优完工时间，则

$$C_{\max}\le\left(2-\frac{1}{m}\right)C^*$$

::: details 证明思路
设最后完成的作业为 $j$，它在机器 $k$ 上开始的时间为 $T$。由于 LPT 总是把作业分给当前负载最小的机器，在分配 $j$ 时，机器 $k$ 的负载是所有机器中最小的，因此

$$T\le\frac{1}{m}\left(\sum_{i\ne j}p_i\right)\le\frac{1}{m}\sum_{i=1}^{n}p_i$$

而最优解至少需要 $\frac{1}{m}\sum p_i$ 的时间，且至少需要 $p_j$ 的时间，故

$$C^*\ge\max\left\{\frac{1}{m}\sum p_i,\ p_j\right\}$$

于是

$$C_{\max}=T+p_j\le\frac{1}{m}\sum p_i+p_j\le C^*+\left(1-\frac{1}{m}\right)C^*=\left(2-\frac{1}{m}\right)C^*$$
:::

### 贪心不一定最优的例子

$m=2$，作业时间 $\{3,3,2,2,2\}$，总时间 $12$。

- LPT：先分 $3,3$（两台各 $3$），再分 $2,2$（各变 $5$），最后 $2$ 分给任一台（变 $7$）。完工时间 $7$。
- 最优：一台做 $3+3=6$，另一台做 $2+2+2=6$，完工时间 $6$。

| 调度 | 机器 1 | 机器 2 | 完工时间 |
| :--- | :--- | :--- | ---: |
| LPT | $3+2+2=7$ | $3+2=5$ | 7 |
| 最优 | $3+3=6$ | $2+2+2=6$ | 6 |

::: tip 近似算法的评价
对 NP 难问题，我们不追求“最优”，而追求“**在多项式时间内接近最优**”。LPT 的近似比 $2-\frac{1}{m}$ 是一个**最坏情况保证**：无论输入多坏，LPT 的结果都不会超过最优解的 $2$ 倍。实际数据上，LPT 通常远好于这个界。
:::

## 6.2.5 三个问题的对比

| 问题 | 贪心指标 | 复杂度 | 是否最优 |
| :--- | :--- | :--- | :--- |
| 活动安排 | 结束时间最早 | $O(n\log n)$ | 是 |
| 分数背包 | 单位价值最高 | $O(n\log n)$ | 是 |
| 最优装载 | 重量最轻 | $O(n\log n)$ | 是 |
| 多机调度 | 最长作业优先，分给最空机器 | $O(n\log n)$ | 否，近似比 $2-1/m$ |
| 0-1 背包 | 单位价值最高 | $O(n\log n)$ | 否（反例见 6.1） |
