# 6.5 多机调度与流水作业调度

## 6.5.1 多机调度问题（回顾）

$n$ 个作业、$m$ 台相同机器，作业 $i$ 的处理时间为 $p_i$，求最小化最大完工时间的调度。该问题是 NP 难的，LPT（最长处理时间优先）贪心给出 $2-\frac{1}{m}$ 的近似比。

LPT 的核心操作是“每次把当前最长的作业分给当前负载最小的机器”，用最小堆维护机器负载即可在 $O(n\log n+n\log m)$ 内完成。

::: tip 多机调度的下界
对任意实例，最优完工时间满足

$$C^*\ge\max\left\{\max_i p_i,\ \frac{1}{m}\sum_{i=1}^{n}p_i\right\}$$

这两个下界常被用作分支限界法的初始下界，也可以用来评估贪心解的质量。
:::

## 6.5.2 流水作业调度问题

### 问题描述

$n$ 个作业要在两台机器 $M_1$、$M_2$ 组成的流水线上加工。每个作业必须先经过 $M_1$，再经过 $M_2$；作业 $i$ 在 $M_1$、$M_2$ 上的时间分别为 $a_i$、$b_i$。求最优加工顺序，使总完工时间最小。

与多机调度的区别：

- 多机调度：每个作业只需一道工序，可任选一台机器；
- 流水作业：每个作业有两道工序，且**工序顺序固定**（先 $M_1$ 后 $M_2$），所有作业走同一条流水线。

### 为什么不能简单贪心

一个直观想法是“先加工 $a_i$ 小的”或“先加工 $b_i$ 小的”，但都不对。例如：

| 作业 | $a_i$ | $b_i$ |
| :--- | ---: | ---: |
| 1 | 2 | 1 |
| 2 | 3 | 1 |
| 3 | 2 | 3 |

按 $a$ 升序（1,3,2 或 3,1,2）与按 $b$ 升序（1,2,3）会得到不同结果，需要更精细的规则。

### 最优子结构

设 $S\subseteq N$，$t$ 为 $M_2$ 还需等待的时间。则

$$T(S,t)=\min_{i\in S}\Bigl\{a_i+T\bigl(S-\{i\},\ b_i+\max\{t-a_i,0\}\bigr)\Bigr\}$$

原问题为 $T(N,0)$。这个递推的状态是指数级的，不能直接用来求多项式算法，但它揭示了“相邻作业如何比较”的关键。

### 相邻交换：Johnson 不等式

设某调度中相邻两个作业为 $i,j$。比较顺序 $ij$ 与 $ji$ 的完工时间，可以推出：若

$$\min\{b_i,a_j\}\ge\min\{b_j,a_i\}$$

则 $i$ 排在 $j$ 前面不劣于 $j$ 排在 $i$ 前面。这个不等式称为 **Johnson 不等式**。

::: details 推导思路
设 $M_2$ 开始加工这两个作业前已等待 $t$。顺序 $ij$ 下，两个作业在 $M_2$ 上的完成时间之和为

$$T_{ij}=a_i+a_j+\max\{t-a_i-a_j,\ a_j-a_i-b_i,\ 0\}$$

顺序 $ji$ 下为

$$T_{ji}=a_i+a_j+\max\{t-a_i-a_j,\ a_i-a_j-b_j,\ 0\}$$

比较两个 max 中的项，可证 Johnson 不等式成立时 $T_{ij}\le T_{ji}$。
:::

进一步可以证明：**一个调度满足 Johnson 法则（任意相邻作业都满足上述不等式），当且仅当它是最优调度**。

### Johnson 算法

1. 把作业分成两组：

$$N_1=\{i\mid a_i<b_i\},\qquad N_2=\{i\mid a_i\ge b_i\}$$

2. $N_1$ 中的作业按 $a_i$ **非减序**排列；
3. $N_2$ 中的作业按 $b_i$ **非增序**排列；
4. 将 $N_1$ 接在 $N_2$ 前面。

```java
List<Integer> johnson(int[] a, int[] b, int n) {
    List<Integer> n1 = new ArrayList<>(), n2 = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        if (a[i] < b[i]) n1.add(i);
        else n2.add(i);
    }
    n1.sort(Comparator.comparingInt(i -> a[i]));
    n2.sort((i, j) -> b[j] - b[i]);
    n1.addAll(n2);
    return n1;
}
```

时间复杂度 $O(n\log n)$，空间 $O(n)$。

::: details 为什么这样排序满足 Johnson 法则？
- 若 $i,j\in N_1$，则 $a_i<b_i$、$a_j<b_j$。按 $a$ 升序，$a_i\le a_j$，于是 $\min\{b_i,a_j\}\ge a_i$，而 $\min\{b_j,a_i\}\le a_i$，不等式成立。
- 若 $i,j\in N_2$，则 $a_i\ge b_i$、$a_j\ge b_j$。按 $b$ 降序，$b_i\ge b_j$，于是 $\min\{b_i,a_j\}\ge b_j$，而 $\min\{b_j,a_i\}\le b_j$，不等式成立。
- 若 $i\in N_1$、$j\in N_2$，则 $b_i>a_i$ 且 $a_j\ge b_j$。可验证 $\min\{b_i,a_j\}\ge\min\{b_j,a_i\}$ 恒成立。

因此 $N_1$ 在前、$N_2$ 在后的排列满足 Johnson 法则。
:::

### 一个完整例子

三个作业：

| 作业 | $a_i$ | $b_i$ |
| :--- | ---: | ---: |
| 1 | 2 | 1 |
| 2 | 3 | 1 |
| 3 | 2 | 3 |

分组：

- $N_1=\{3\}$（$2<3$），按 $a$ 升序：$\{3\}$；
- $N_2=\{1,2\}$（$2\ge1$、$3\ge1$），按 $b$ 降序：$\{1,2\}$。

最优顺序：$3,1,2$。

时间线：

| 时段 | $M_1$ | $M_2$ |
| :--- | :--- | :--- |
| $[0,2]$ | 作业 3 | 空闲 |
| $[2,4]$ | 作业 1 | 作业 3 |
| $[4,5]$ | — | 作业 3 完成，作业 1 尚未到达？ |
| $[4,7]$ | 作业 2 | 作业 1（$[4,5]$），作业 2（$[7,8]$） |

更准确地列出每个作业的起止时间：

| 作业 | $M_1$ 起止 | $M_2$ 起止 |
| :--- | :--- | :--- |
| 3 | $[0,2]$ | $[2,5]$ |
| 1 | $[2,4]$ | $[5,6]$ |
| 2 | $[4,7]$ | $[7,8]$ |

总完工时间 $8$。若按 $1,2,3$ 加工，总完工时间为 $10$。

### 与动态规划的关系

流水作业调度在动态规划章节出现，是因为 $T(S,t)$ 的递推完美展示了最优子结构；但最终的高效算法是 Johnson 贪心。考试中：

- 问“最优子结构/递推方程”：写 $T(S,t)$；
- 问“设计算法”：写 Johnson 分组排序，并说明复杂度；
- 问“正确性”：用相邻交换论证 Johnson 不等式。

::: warning 三台机器就不行了
Johnson 算法只适用于 **两台机器** 的流水作业。三台及以上机器的流水作业调度是 NP 难的，没有类似的简单贪心规则，需要分支限界、启发式或近似算法。
:::

## 6.5.3 两类调度问题的对比

| 维度 | 多机调度 | 流水作业调度 |
| :--- | :--- | :--- |
| 机器 | $m$ 台并行，功能相同 | 2 台串行，工序固定 |
| 每个作业 | 一道工序 | 两道工序（先 M1 后 M2） |
| 目标 | 最小化最大完工时间 | 最小化总完工时间 |
| 精确算法 | NP 难 | 2 台机器有 Johnson 多项式算法 |
| 贪心策略 | LPT，近似比 $2-1/m$ | Johnson 法则，最优 |
| 复杂度 | $O(n\log n)$ | $O(n\log n)$ |

::: tip 调度问题的统一视角
调度问题的三要素是：**机器环境**（单机/并行/流水/车间）、**约束**（先后顺序、释放时间、截止期）、**目标**（最大完工时间、总完成时间、延迟）。改变其中任何一个，问题的难度和算法都会改变。学习时不要死记某个算法，而要能判断“当前问题属于哪一类、有没有可用的贪心规则、若没有该用什么近似方法”。
:::
