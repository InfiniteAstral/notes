# 6.4 最小生成树与单源最短路径

## 6.4.1 最小生成树问题

给定一个连通无向图 $G=(V,E)$，每条边 $(u,v)$ 有权值 $w(u,v)$。**生成树**是包含所有顶点、边数为 $|V|-1$ 的连通无环子图。**最小生成树（MST）** 是边权之和最小的生成树。

### 两个基本性质

**切分性质（Cut Property）**：对任意把顶点分成两个非空集合的切分 $(S,V-S)$，横跨该切分的最小权边一定属于某棵 MST。

**环路性质（Cycle Property）**：对任意环，环上权值最大的边一定不属于任何 MST（若权值唯一）。

::: details 切分性质的证明
设 $e=(u,v)$ 是横跨切分 $(S,V-S)$ 的最小权边。取一棵 MST $T$，若 $e\notin T$，则 $T$ 中存在从 $u$ 到 $v$ 的路径，该路径必有一条边 $e'$ 横跨切分。把 $e'$ 换成 $e$，得到一棵新树，权值不增，故仍是最小生成树。因此存在包含 $e$ 的 MST。
:::

这两个性质是 Prim 与 Kruskal 正确性的共同基础。

## 6.4.2 Prim 算法

### 思想

从任意一个顶点开始，维护一个已加入 MST 的顶点集合 $S$。每次选择**连接 $S$ 与 $V-S$ 的最小权边**，把对应的顶点加入 $S$，直到所有顶点都加入。

```text
prim(G, w, r)
for each u in V
    key[u] ← ∞
    parent[u] ← NIL
key[r] ← 0
S ← ∅
Q ← V                           // 以 key 为键的最小优先队列
while Q ≠ ∅
    u ← Q.extractMin()
    S ← S ∪ {u}
    for each v in Adj[u]
        if v ∉ S and w(u,v) < key[v]
            key[v] ← w(u,v)
            parent[v] ← u
```

```java
int prim(int[][] w, int n) {
    boolean[] inMST = new boolean[n];
    int[] key = new int[n];
    Arrays.fill(key, Integer.MAX_VALUE);
    key[0] = 0;
    int total = 0;
    for (int i = 0; i < n; i++) {
        int u = -1;
        for (int v = 0; v < n; v++)
            if (!inMST[v] && (u == -1 || key[v] < key[u])) u = v;
        inMST[u] = true;
        total += key[u];
        for (int v = 0; v < n; v++)
            if (!inMST[v] && w[u][v] < key[v]) key[v] = w[u][v];
    }
    return total;
}
```

### 复杂度

- 邻接矩阵 + 线性扫描：$O(n^2)$，适合稠密图；
- 邻接表 + 二叉堆：$O(m\log n)$，适合稀疏图；
- 斐波那契堆：$O(m+n\log n)$。

### 正确性

每次选择的边都是横跨切分 $(S,V-S)$ 的最小边，由切分性质，它属于某棵 MST。归纳可知 Prim 构造的树是最小生成树。

## 6.4.3 Kruskal 算法

### 思想

把所有边按权值从小到大排序，依次考虑每条边：若它连接两个不同的连通分量，则加入 MST；否则（会形成环）丢弃。直到选够 $n-1$ 条边。

```text
kruskal(G, w)
A ← ∅
for each v in V
    MakeSet(v)
按 w 升序排序 E
for each (u,v) in E
    if Find(u) ≠ Find(v)
        A ← A ∪ {(u,v)}
        Union(u, v)
return A
```

```java
class DSU {
    int[] p, r;
    DSU(int n) { p = new int[n]; r = new int[n];
        for (int i = 0; i < n; i++) p[i] = i; }
    int find(int x) { return p[x] == x ? x : (p[x] = find(p[x])); }
    boolean union(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (r[x] < r[y]) { int t = x; x = y; y = t; }
        p[y] = x;
        if (r[x] == r[y]) r[x]++;
        return true;
    }
}
```

### 复杂度

排序 $O(m\log m)$，并查集操作近似 $O(m\alpha(n))$，总复杂度 $O(m\log m)$。适合稀疏图。

### 正确性

每次选中的边 $(u,v)$ 是当前横跨“$u$ 所在连通分量”与其余部分的最小边（因为边已按权值排序，之前更小的边都没能连接这两个分量）。由切分性质，它属于某棵 MST。归纳得 Kruskal 正确。

::: tip Prim 还是 Kruskal？
| 场景 | 推荐 | 原因 |
| :--- | :--- | :--- |
| 稠密图（$m\approx n^2$） | Prim（邻接矩阵） | $O(n^2)$ 优于 $O(n^2\log n)$ |
| 稀疏图（$m\approx n$） | Kruskal | $O(m\log m)$ 更小 |
| 边已按权值给出 | Kruskal | 省去排序 |
| 需要动态加边 | Kruskal + 并查集 | 易于增量维护 |
:::

## 6.4.4 一个 MST 的例子

设图有 6 个顶点，边及权值如下：

| 边 | 权值 |
| :--- | ---: |
| B–C | 1 |
| A–C | 2 |
| D–E | 2 |
| E–F | 3 |
| A–B | 4 |
| B–D | 5 |
| D–F | 6 |
| C–D | 8 |
| C–E | 10 |

Kruskal 过程：

| 步骤 | 考虑边 | 权值 | 动作 | 已选边 |
| ---: | :--- | ---: | :--- | :--- |
| 1 | B–C | 1 | 加入 | B–C |
| 2 | A–C | 2 | 加入 | B–C, A–C |
| 3 | D–E | 2 | 加入 | B–C, A–C, D–E |
| 4 | E–F | 3 | 加入 | +E–F |
| 5 | A–B | 4 | 成环，丢弃 | 不变 |
| 6 | B–D | 5 | 加入 | 选够 5 条边 |

MST 总权值 $1+2+2+3+5=13$。

## 6.4.5 单源最短路径：Dijkstra 算法

### 问题

给定带权有向图 $G=(V,E)$，所有边权非负，求从源点 $s$ 到其余各顶点的最短路径长度。

### 思想

维护已确定最短距离的顶点集合 $S$。每次从 $V-S$ 中选出**当前距离最小**的顶点 $u$，把 $u$ 加入 $S$，并用 $u$ 松弛它的邻居：

$$\text{dist}[v]\leftarrow\min\{\text{dist}[v],\ \text{dist}[u]+w(u,v)\}$$

```text
dijkstra(G, w, s)
for each v in V
    dist[v] ← ∞
    prev[v] ← NIL
dist[s] ← 0
S ← ∅
Q ← V
while Q ≠ ∅
    u ← Q.extractMin()          // 取 dist 最小的顶点
    S ← S ∪ {u}
    for each v in Adj[u]
        if dist[u] + w(u,v) < dist[v]
            dist[v] ← dist[u] + w(u,v)
            prev[v] ← u
```

```java
void dijkstra(int[][] w, int s, int n) {
    int[] dist = new int[n];
    boolean[] done = new boolean[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[s] = 0;
    for (int i = 0; i < n; i++) {
        int u = -1;
        for (int v = 0; v < n; v++)
            if (!done[v] && (u == -1 || dist[v] < dist[u])) u = v;
        if (dist[u] == Integer.MAX_VALUE) break;
        done[u] = true;
        for (int v = 0; v < n; v++)
            if (!done[v] && w[u][v] < Integer.MAX_VALUE
                && dist[u] + w[u][v] < dist[v])
                dist[v] = dist[u] + w[u][v];
    }
}
```

### 复杂度

- 邻接矩阵 + 线性扫描：$O(n^2)$；
- 邻接表 + 二叉堆：$O((n+m)\log n)$；
- 斐波那契堆：$O(m+n\log n)$。

### 正确性

::: details 贪心选择为什么成立？
当 $u$ 被取出时，$\text{dist}[u]$ 是所有未确定顶点中最小的。假设存在一条更短的路径 $s\leadsto u$，它必然在某个位置第一次离开已确定集合 $S$，设经过边 $(x,y)$，$x\in S$，$y\notin S$。由于边权非负，

$$\text{dist}[y]\le\text{dist}[x]+w(x,y)\le\text{该路径长度}<\text{dist}[u]$$

这与“$u$ 是当前最小”矛盾。因此 $\text{dist}[u]$ 已是最终最短距离。
:::

::: warning 负权边会让 Dijkstra 失效
反例：$A\to B$ 权 $1$，$A\to C$ 权 $2$，$C\to B$ 权 $-2$。

Dijkstra 先确定 $B$ 的距离为 $1$（因为 $1<2$），之后不再更新；但真实最短路径是 $A\to C\to B$，长度为 $0$。

**负权图应使用 Bellman–Ford 算法**（$O(nm)$），它允许负边并能检测负环；多源最短路用 Floyd 算法（$O(n^3)$）。
:::

## 6.4.6 三种图算法的比较

| 算法 | 解决什么问题 | 贪心指标 | 复杂度 | 适用条件 |
| :--- | :--- | :--- | :--- | :--- |
| Prim | MST | 连接已选集合的最小边 | $O(n^2)$ / $O(m\log n)$ | 连通无向图 |
| Kruskal | MST | 全局最小且不成环的边 | $O(m\log m)$ | 连通无向图 |
| Dijkstra | 单源最短路 | 当前距离最小的顶点 | $O(n^2)$ / $O(m\log n)$ | **非负权** |

::: info 为什么 Prim 和 Dijkstra 长得像？
两者都维护一个“已确定集合”，每次选一个最优顶点加入。区别在于“最优”的定义：

- Prim 选**连接集合的最小边**，目标是让整棵树的总权最小；
- Dijkstra 选**距离源点最近的顶点**，目标是让单点到所有点的路径最短。

一个关注“边”，一个关注“路径”，这就是它们本质的不同。
:::
