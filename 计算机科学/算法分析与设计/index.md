# 《算法分析与设计》

::: info 本学科的贡献者

**算法是解决问题的一种方法或过程，是由若干条指令组成的有穷序列**。它接受符合规范的输入，在有限时间内产生所要求的输出。如果说微积分成就了现代科学，那么算法就成就了现代世界——从交通调度、网络路由到基因测序与大模型推理，几乎所有大规模计算问题的背后，都是一次次“把问题变简单”的算法设计。

**算法分析与设计**研究两件事：一是**如何设计**求解问题的算法，二是**如何评价**算法的好坏。前者提供分治、动态规划、贪心、回溯、分支限界、遗传等一整套设计策略；后者提供以渐近记号为核心的效率分析工具，让我们在写完算法之前就能判断它能否承受真实规模的数据。

本课程的主线可以概括为四个递进的层次：

| 层次 | 关注对象 | 核心问题 | 对应工具 |
| :--- | :--- | :--- | :--- |
| 问题 | 问题类 | 这类问题难不难？ | 问题复杂性分析 |
| 算法类 | 一类算法 | 这类算法的效率上界在哪？ | 算法分析技术 |
| 算法 | 单个算法 | 它为什么正确？有多快？ | 正确性证明、复杂度分析 |
| 问题实例 | 具体输入 | 怎样求出答案？ | 算法设计技术 |

::: tip 学习建议
- **先想清楚“解长什么样”**：解向量、解空间、约束条件是所有算法设计的起点。
- **把每个算法都写成三段**：思想（一句话）→ 伪代码（能默写）→ 复杂度（会推导）。考场上能复现的只有这三样。
- **动态规划、回溯法、分支限界法是本课程的重点与难点**，务必做到“见到问题能建模、见到代码能填空、见到递推能求解”。
:::
