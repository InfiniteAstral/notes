# 10.2 公式、模板与易错点速查

## 10.2.1 求和与渐近公式

$$\sum_{k=1}^{n}k=\frac{n(n+1)}{2},\qquad \sum_{k=1}^{n}k^2=\frac{n(n+1)(2n+1)}{6}$$

$$\sum_{k=1}^{n}k^3=\left(\frac{n(n+1)}{2}\right)^2$$

$$\sum_{k=0}^{n}q^k=\frac{1-q^{n+1}}{1-q}\ (q\ne1),\qquad \sum_{k=0}^{n}2^k=2^{n+1}-1$$

$$\sum_{k=1}^{n}\frac{1}{k}=\ln n+O(1),\qquad \sum_{k=1}^{n}\log k=\Theta(n\log n)$$

$$\log(n!)=\Theta(n\log n),\qquad n!=\omega(2^n),\qquad n!=o(n^n)$$

$$\log_a n=\Theta(\log_b n),\qquad \log n=o(n^\alpha),\qquad n^\alpha=o(b^n)\ (b>1,\alpha>0)$$

## 10.2.2 主定理

对 $T(n)=aT(n/b)+f(n)$，$a\ge1,b>1$，令 $n^{\log_b a}$ 为“子问题总代价”：

| 情形 | 条件 | 解 |
| :--- | :--- | :--- |
| 1 | $f(n)=O(n^{\log_b a-\varepsilon})$ | $\Theta(n^{\log_b a})$ |
| 2 | $f(n)=\Theta(n^{\log_b a})$ | $\Theta(n^{\log_b a}\log n)$ |
| 3 | $f(n)=\Omega(n^{\log_b a+\varepsilon})$ 且正则 | $\Theta(f(n))$ |

### 常见递推速查

| 递推 | 解 | 典型算法 |
| :--- | :--- | :--- |
| $T(n)=T(n/2)+1$ | $\Theta(\log n)$ | 二分查找 |
| $T(n)=2T(n/2)+n$ | $\Theta(n\log n)$ | 归并排序、快排平均 |
| $T(n)=2T(n/2)+1$ | $\Theta(n)$ | 分治求和 |
| $T(n)=4T(n/2)+n$ | $\Theta(n^2)$ | 大整数（4 次乘法） |
| $T(n)=3T(n/2)+n$ | $\Theta(n^{1.585})$ | Karatsuba |
| $T(n)=7T(n/2)+n^2$ | $\Theta(n^{2.807})$ | Strassen |
| $T(n)=8T(n/2)+n^2$ | $\Theta(n^3)$ | 分块矩阵乘法 |
| $T(n)=T(n-1)+1$ | $\Theta(n)$ | 插入排序最好 |
| $T(n)=T(n-1)+n$ | $\Theta(n^2)$ | 插入排序最坏 |
| $T(n)=2T(n-1)+1$ | $\Theta(2^n)$ | 汉诺塔 |
| $T(n)=T(n/3)+T(2n/3)+n$ | $\Theta(n\log n)$ | 递归树 |
| $T(n)=T(n/5)+T(7n/10)+n$ | $\Theta(n)$ | 线性时间选择 |

## 10.2.3 动态规划方程速查

### 矩阵连乘

$$m[i][j]=\min_{i\le k<j}\{m[i][k]+m[k+1][j]+p_{i-1}p_kp_j\},\qquad m[i][i]=0$$

### 凸多边形三角剖分

$$t[i][j]=\min_{i\le k<j}\{t[i][k]+t[k+1][j]+w(v_{i-1},v_k,v_j)\},\qquad t[i][i]=0$$

### LCS

$$c[i][j]=\begin{cases}
0, & i=0\ \text{或}\ j=0\\
c[i-1][j-1]+1, & x_i=y_j\\
\max\{c[i-1][j],c[i][j-1]\}, & x_i\ne y_j
\end{cases}$$

### 最大子段和

$$b[j]=\max\{b[j-1]+a_j,\ a_j\},\qquad b[1]=a_1$$

### 0-1 背包

$$m(i,j)=\begin{cases}
0, & i=0\ \text{或}\ j=0\\
m(i-1,j), & j<w_i\\
\max\{m(i-1,j),m(i-1,j-w_i)+v_i\}, & j\ge w_i
\end{cases}$$

### 完全背包

$$m(i,j)=\max\{m(i-1,j),\ m(i,j-w_i)+v_i\}$$

### 图像压缩

$$s[i]=\min_{1\le k\le\min(i,256)}\{s[i-k]+k\cdot\text{bmax}(i-k+1,i)\}+11,\qquad s[0]=0$$

### 最优二叉搜索树

$$m[i][j]=\min_{i\le k\le j}\{m[i][k-1]+m[k+1][j]\}+w[i][j],\qquad m[i][i-1]=0$$

### 投资问题

$$F(k,x)=\max_{0\le y\le x}\{F(k-1,x-y)+f_k(y)\},\qquad F(1,x)=f_1(x)$$

### 流水作业调度

$$T(S,t)=\min_{i\in S}\{a_i+T(S-\{i\},\ b_i+\max\{t-a_i,0\})\}$$

## 10.2.4 回溯法模板

### 递归

```text
void backtrack(int t) {
    if (t > n) output(x);
    else
        for (int i = f(n, t); i <= g(n, t); i++) {
            x[t] = h(i);
            if (constraint(t) && bound(t))
                backtrack(t + 1);
        }
}
```

### 迭代

```text
int t = 1;
while (t > 0) {
    if (f[t] <= n) {
        x[t] = f[t];
        if (constraint(t) && bound(t)) {
            if (t == n) { output(x); f[t]++; }
            else { t++; f[t] = 1; }
        } else f[t]++;
    } else {
        f[t] = 1; t--;
        if (t > 0) f[t]++;
    }
}
```

## 10.2.5 分支限界法模板

```text
Q = {root}
while Q 非空:
    u = select(Q)                  // FIFO 或按界优先
    for each child v of u:
        if feasible(v) and promising(v):
            Q.add(v)
```

- 极大化：`promising(v)` 为 `UB(v) > cBest`；
- 极小化：`promising(v)` 为 `LB(v) < cBest`。

### 结点结构

```text
Node {
    level
    parent
    leftChild
    state fields (cw, cv, cc, sf2, ...)
    bound
}
```

## 10.2.6 贪心公式速查

### 活动安排

按 $f_i$ 升序，选与上一个相容的活动；$O(n\log n)$。

### 分数背包

按 $v_i/w_i$ 降序，能装整件装整件，否则装一部分；$O(n\log n)$。

### 最优装载

按 $w_i$ 升序，能装就装；$O(n\log n)$。

### 哈夫曼

每次合并频率最小的两棵树；$WPL=\sum w_i l_i$；$O(n\log n)$。

### Johnson 流水作业

$$N_1=\{i:a_i<b_i\}\ \text{按 }a_i\text{ 升序},\qquad N_2=\{i:a_i\ge b_i\}\ \text{按 }b_i\text{ 降序}$$

$N_1$ 接 $N_2$；$O(n\log n)$。

### LPT 多机调度

按 $p_i$ 降序，每次分给负载最小的机器；近似比 $2-\frac{1}{m}$。

## 10.2.7 易错点清单

### 基础与效率分析

1. 把 $O$ 当成“等于”，认为 $n=O(n^2)$ 和 $n^2=O(n)$ 都成立；
2. 忘记 $\Theta$ 要求上下界同时成立；
3. 主定理情形 2 忘记乘 $\log n$；
4. 递归式初始条件写错；
5. 把“基本操作次数”与“语句执行次数”混为一谈。

### 分治

1. 子问题不独立却硬用分治（应改 DP）；
2. 合并代价算错（如最近点对忘记带宽内检查）；
3. 快速排序最坏 $O(n^2)$ 写成 $O(n\log n)$；
4. 归并排序空间 $O(1)$（应为 $O(n)$）；
5. 棋盘覆盖骨牌数写成 $4^k$（应为 $(4^k-1)/3$）。

### 动态规划

1. 状态定义不完整，导致有后效性；
2. 转移方程漏决策；
3. 边界 $i=0$ 或 $j=0$ 未初始化；
4. 0-1 背包一维数组正序（应为倒序）；
5. 忘记构造最优解；
6. 图像压缩分段长度忘记 $\le256$；
7. 最优 BST 忘记加 $w[i][j]$。

### 贪心

1. 0-1 背包用贪心（反例）；
2. 活动安排按开始时间排序（应按结束时间）；
3. 贪心正确性不证明；
4. Dijkstra 用于负权图；
5. 多机调度贪心当成最优（只是近似）。

### 回溯与分支限界

1. 不满足多米诺性质却剪枝；
2. 忘记恢复现场（排列、`cw`、`cv`、标记数组）；
3. 回溯的 `bound` 用于“求所有解”，漏解；
4. 分支限界的界方向搞反；
5. FIFO 忘记层标记；
6. 优先队列的界不是“最终目标值”，无法比较；
7. 认为分支限界一定比回溯快。

### 遗传算法

1. 适应度出现负数，轮盘赌失效；
2. 排列编码用单点交叉，产生重复/缺失；
3. 变异概率过大，退化为随机搜索；
4. 没有精英保留，最优解丢失；
5. 声称 GA 能保证全局最优。

## 10.2.8 算法设计题答题模板

::: tip 五步答题法
**第一步：建模（2–3 行）**
- 说明解向量 $x$、每个分量的含义与取值范围；
- 写出目标函数与约束。

**第二步：说明算法思想（1–2 行）**
- 例如“采用动态规划，设 $dp[i][j]$ 表示……”。

**第三步：写伪代码（核心）**
- 边界初始化；
- 循环/递归；
- 返回答案；
- 关键剪枝/转移要写清楚。

**第四步：复杂度分析**
- 状态数 × 每个状态的转移代价；
- 空间；
- 最好/最坏/平均（若不同）。

**第五步：正确性说明（可选但加分）**
- 最优子结构/贪心选择/归纳法/循环不变式。
:::

### 示例：0-1 背包的答题框架

> **建模**：令 $x_i\in\{0,1\}$ 表示第 $i$ 件物品是否装入，目标 $\max\sum v_ix_i$，约束 $\sum w_ix_i\le c$。
>
> **状态**：$dp[i][j]$ 表示前 $i$ 件物品、容量 $j$ 的最大价值。
>
> **转移**：
> $$dp[i][j]=\max\{dp[i-1][j],\ dp[i-1][j-w_i]+v_i\}\quad(j\ge w_i)$$
> 否则 $dp[i][j]=dp[i-1][j]$。
>
> **边界**：$dp[0][j]=0$，$dp[i][0]=0$。
>
> **答案**：$dp[n][c]$；若需方案，从 $dp[n][c]$ 回溯。
>
> **复杂度**：时间 $O(nc)$，空间 $O(nc)$（可优化到 $O(c)$）。

## 10.2.9 五分钟自测

::: details 题目
1. 求 $T(n)=2T(n/2)+n\log n$ 的阶。
2. 0-1 背包：$n=3,c=10$，$w=\{5,4,6\}$，$v=\{10,40,30\}$，求最优值。
3. 求 $X=\text{ABCBDAB}$ 与 $Y=\text{BDCABA}$ 的 LCS 长度。
4. $N=4$ 皇后有多少个解？
5. 活动集合 $(s,f)$：$(1,4),(3,5),(0,6),(5,7),(3,9),(5,9),(6,10),(8,11),(8,12),(2,14),(12,16)$，求最大相容活动数。
:::

::: details 答案
1. $f(n)=n\log n=\Theta(n^1\log n)$，属于主定理情形 2 的推广，$T(n)=\Theta(n\log^2 n)$。
2. 按单位价值：物品 2（10）、物品 3（5）、物品 1（2）。装 2（$w=4,v=40$），再装 3（$w=6,v=30$），总重 $10$，价值 $70$。最优值 $70$。
3. LCS 长度为 $4$，例如 `BCBA`。
4. $N=4$ 时共有 $2$ 个解：`2 4 1 3` 与 `3 1 4 2`（列号）。
5. 按结束时间排序后贪心：$(1,4),(5,7),(8,11),(12,16)$，共 $4$ 个。
:::

::: warning 最后提醒
- 考试是**闭卷**，公式要能默写；
- 算法设计题**不要留白**，写出建模与思路就有分；
- 复杂度分析要写清楚“为什么”；
- 遇到不会的题，先写暴力解法，再说优化方向。
:::
