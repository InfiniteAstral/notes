# 5.7 投资问题

## 5.7.1 问题描述

有 $m$ 万元钱和 $n$ 个投资项目。函数 $f_i(x)$ 表示把 $x$ 万元投入第 $i$ 个项目所产生的效益（$i=1,2,\dots,n$）。如何分配这 $m$ 万元，使投资的总效益最高？

形式化地：

$$\max \sum_{i=1}^{n} f_i(x_i)$$

满足

$$\sum_{i=1}^{n}x_i=m,\qquad x_i\in\mathbb{N}$$

这是一个典型的**资源分配问题**：把钱（资源）分给若干项目，每个项目的收益只与分给它的钱数有关。

::: tip 为什么不能用“按边际收益贪心”？
如果每个 $f_i$ 都是凹函数（边际收益递减），按“当前边际收益最大”贪心确实能得到最优解。但题目给出的 $f_i$ 可以是任意函数（可能先增后减、可能有跳跃），贪心没有正确性保证。因此需要用动态规划枚举分配方案。
:::

## 5.7.2 状态与转移

设 $F(k,x)$ 表示把 $x$ 万元投给前 $k$ 个项目所能获得的最大收益，其中 $k=1,2,\dots,n$，$x=0,1,\dots,m$。

**边界**：只有一个项目时，全部钱都投给它：

$$F(1,x)=f_1(x)$$

**转移**：考虑第 $k$ 个项目分到 $x_k$ 万元（$0\le x_k\le x$），剩下的 $x-x_k$ 万元投给前 $k-1$ 个项目：

$$F(k,x)=\max_{0\le x_k\le x}\Bigl\{F(k-1,x-x_k)+f_k(x_k)\Bigr\}$$

**答案**：$F(n,m)$。

同时用 $x_k(k,x)$ 记录取得最大值的分配额，便于回溯。

## 5.7.3 算例

有 $5$ 万元、$4$ 个项目，效益函数如下（单位：万元）：

| $x$ | $f_1(x)$ | $f_2(x)$ | $f_3(x)$ | $f_4(x)$ |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0 | 0 | 0 | 0 |
| 1 | 11 | 0 | 2 | 20 |
| 2 | 12 | 5 | 10 | 21 |
| 3 | 13 | 10 | 30 | 22 |
| 4 | 14 | 15 | 32 | 23 |
| 5 | 15 | 20 | 40 | 24 |

### 计算 $F(2,x)$

$$F(2,x)=\max_{0\le y\le x}\{F(1,x-y)+f_2(y)\}=\max_{0\le y\le x}\{f_1(x-y)+f_2(y)\}$$

| $x$ | 计算 | $F(2,x)$ | 最优 $x_2$ |
| ---: | :--- | ---: | ---: |
| 1 | $\max\{11+0,\ 0+0\}$ | 11 | 0 |
| 2 | $\max\{12,\ 11+0,\ 0+5\}$ | 12 | 0 |
| 3 | $\max\{13,\ 12,\ 11+5,\ 10\}$ | 16 | 2 |
| 4 | $\max\{14,\ 13,\ 12+5,\ 11+10,\ 15\}$ | 21 | 3 |
| 5 | $\max\{15,\ 14,\ 13+5,\ 12+10,\ 11+15,\ 20\}$ | 26 | 4 |

### 计算 $F(3,x)$

| $x$ | $F(3,x)$ | 最优 $x_3$ |
| ---: | ---: | ---: |
| 1 | 11 | 0 |
| 2 | 13 | 1 |
| 3 | 30 | 3 |
| 4 | 41 | 3 |
| 5 | 43 | 4 |

### 计算 $F(4,x)$

| $x$ | $F(4,x)$ | 最优 $x_4$ |
| ---: | ---: | ---: |
| 1 | 20 | 1 |
| 2 | 31 | 1 |
| 3 | 33 | 1 |
| 4 | 50 | 1 |
| 5 | 61 | 1 |

最终 $F(4,5)=61$。

### 回溯最优分配

从 $F(4,5)=61$ 出发：

- $x_4=1$，剩余 $4$ 万元给前 $3$ 个项目；
- $F(3,4)=41$，$x_3=3$，剩余 $1$ 万元给前 $2$ 个项目；
- $F(2,1)=11$，$x_2=0$，剩余 $1$ 万元给第 $1$ 个项目；
- $x_1=1$。

最优分配为

$$x_1=1,\quad x_2=0,\quad x_3=3,\quad x_4=1$$

总收益 $11+0+30+20=61$。

## 5.7.4 算法实现

```java
int invest(int n, int m, int[][] f, int[][] F, int[][] xk) {
    // f[i][x] 为第 i 个项目投入 x 万元的效益
    for (int x = 0; x <= m; x++) {
        F[1][x] = f[1][x];
        xk[1][x] = x;
    }
    for (int k = 2; k <= n; k++) {
        for (int x = 0; x <= m; x++) {
            F[k][x] = -1;
            for (int y = 0; y <= x; y++) {
                int val = F[k - 1][x - y] + f[k][y];
                if (val > F[k][x]) {
                    F[k][x] = val;
                    xk[k][x] = y;       // 第 k 个项目分 y 万元
                }
            }
        }
    }
    return F[n][m];
}

void traceback(int n, int m, int[][] xk, int[] x) {
    int rest = m;
    for (int k = n; k >= 1; k--) {
        x[k] = xk[k][rest];
        rest -= x[k];
    }
}
```

### 复杂度

- 状态数 $n(m+1)$；
- 每个状态枚举 $0\le y\le x$，最多 $m+1$ 种；
- 时间 $O(nm^2)$，空间 $O(nm)$。

若 $f_i$ 具有凹性，可以用斜率优化或贪心把复杂度降到 $O(nm)$，但一般情形下 $O(nm^2)$ 是标准做法。

## 5.7.5 与背包问题的联系

| 维度 | 投资问题 | 0-1 背包 | 完全背包 |
| :--- | :--- | :--- | :--- |
| 资源 | 钱（整数） | 容量 | 容量 |
| 对象 | 项目 | 物品 | 物品 |
| 每个对象 | 可分配任意整数 | 选/不选 | 可选多次 |
| 收益 | $f_i(x)$ | $v_i$ | $v_i$ |
| 状态 | $F(k,x)$ | $m(i,j)$ | $m(i,j)$ |
| 转移 | 枚举分配额 | 两种决策 | 枚举件数/正序 |

投资问题可以看作“完全背包”的推广：每个项目不是“选或不选”，而是“分配多少”，收益函数也更一般。

::: tip 资源分配类问题的通用建模
凡是“把总量为 $m$ 的资源分给 $n$ 个对象，每个对象的收益只与分到的量有关”的问题，都可以套用：

$$F(k,x)=\max_{0\le y\le x}\{F(k-1,x-y)+g_k(y)\}$$

例如：生产计划（把工时分给产品）、广告投放（把预算分给渠道）、任务分配（把人手分给任务）。区别只在 $g_k(y)$ 的定义与约束（是否整数、是否有上限）。
:::

## 5.7.6 考试要点

1. 能写出 $F(k,x)$ 的状态定义与转移方程；
2. 能手工填一张小规模的 $F$ 表；
3. 能根据 $x_k(k,x)$ 回溯出最优分配；
4. 能分析 $O(nm^2)$ 的时间复杂度；
5. 能区分投资问题与 0-1 背包、完全背包的异同。
