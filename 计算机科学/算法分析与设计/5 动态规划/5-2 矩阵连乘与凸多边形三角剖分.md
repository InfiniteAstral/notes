# 5.2 矩阵连乘与凸多边形三角剖分

## 5.2.1 矩阵连乘问题

### 问题描述

给定 $n$ 个矩阵 $\{A_1,A_2,\dots,A_n\}$，其中 $A_i$ 与 $A_{i+1}$ 是可乘的（即 $A_i$ 的列数等于 $A_{i+1}$ 的行数）。确定矩阵乘法的**计算顺序**，使得元素相乘的总次数最少。

设 $A_i$ 的维数为 $p_{i-1}\times p_i$，则整条矩阵链的维数可以表示为

$$p_0\times p_1\times p_2\times\cdots\times p_n$$

### 为什么顺序会影响计算量

设有三个矩阵，维数分别为 $10\times100$、$100\times5$、$5\times50$：

- 按 $((A_1A_2)A_3)$ 计算：先算 $A_1A_2$ 需 $10\times100\times5=5000$ 次，再乘 $A_3$ 需 $10\times5\times50=2500$ 次，共 **7500** 次；
- 按 $(A_1(A_2A_3))$ 计算：先算 $A_2A_3$ 需 $100\times5\times50=25000$ 次，再乘 $A_1$ 需 $10\times100\times50=50000$ 次，共 **75000** 次。

同样的三个矩阵，计算量相差 **10 倍**。顺序的重要性可见一斑。

### 蛮力法：卡特兰数

设不同计算次序的数目为 $P(n)$。最后一次乘法必然把链分成左右两段，故

$$P(n)=\sum_{k=1}^{n-1}P(k)P(n-k),\qquad P(1)=1$$

其解为卡特兰数

$$P(n)=C_{n-1}=\frac{1}{n}\binom{2n-2}{n-1}=\Omega\left(\frac{4^n}{n^{3/2}}\right)$$

枚举所有次序是指数级的，不可行。

## 5.2.2 最优子结构

将矩阵连乘积 $A_iA_{i+1}\cdots A_j$ 简记为 $A[i:j]$。设它的最优计算次序在 $A_k$ 与 $A_{k+1}$ 之间断开（$i\le k<j$），则完全加括号方式为

$$\bigl(A_iA_{i+1}\cdots A_k\bigr)\bigl(A_{k+1}\cdots A_j\bigr)$$

总计算量 = 左子链的计算量 + 右子链的计算量 + 两者相乘的计算量。

::: details 最优子结构证明（反证法）
设 $A[i:j]$ 的最优次序在 $k$ 处断开。若 $A[i:k]$ 的次序不是最优的，则存在计算量更小的方式，替换后整个 $A[i:j]$ 的计算量会减少，与“最优”矛盾。右子链同理。

因此，**矩阵连乘问题的最优解包含子问题的最优解**，满足最优子结构性质。
:::

## 5.2.3 递推方程

设 $m[i][j]$ 为计算 $A[i:j]$ 所需的最少数乘次数，则原问题的最优值为 $m[1][n]$。

- 当 $i=j$ 时，只有一个矩阵，不需要乘法：$m[i][i]=0$；
- 当 $i<j$ 时，枚举断点 $k\in[i,j-1]$：

$$m[i][j]=\min_{i\le k<j}\Bigl\{m[i][k]+m[k+1][j]+p_{i-1}\,p_k\,p_j\Bigr\}$$

其中 $p_{i-1}p_kp_j$ 是左子链结果（$p_{i-1}\times p_k$）与右子链结果（$p_k\times p_j$）相乘的代价。

同时用 $s[i][j]$ 记录取得最小值的断点 $k$，用于构造最优解。

## 5.2.4 递归求解为什么慢

直接按递推式写递归：

```java
int recurMatrixChain(int i, int j, int[] p, int[][] s) {
    if (i == j) return 0;
    int u = recurMatrixChain(i, i, p, s)
          + recurMatrixChain(i + 1, j, p, s)
          + p[i - 1] * p[i] * p[j];
    s[i][j] = i;
    for (int k = i + 1; k < j; k++) {
        int t = recurMatrixChain(i, k, p, s)
              + recurMatrixChain(k + 1, j, p, s)
              + p[i - 1] * p[k] * p[j];
        if (t < u) { u = t; s[i][j] = k; }
    }
    return u;
}
```

这个递归的复杂度满足 $T(n)\ge 2^{n-1}$，是指数级的。原因不是子问题多，而是**子问题重复**：不同的有序对 $(i,j)$ 只有

$$\binom{n}{2}+n=\Theta(n^2)$$

个，但递归树却把每个子问题重复计算了许多次。

::: tip 加一张表，指数变多项式
用一个二维数组 `m[i][j]` 记录已算过的结果，递归前先查表，复杂度立刻降到 $O(n^3)$。这就是“记忆化搜索”。而下面的自底向上填表，则完全避免了递归开销。
:::

## 5.2.5 自底向上计算

按**区间长度**从小到大计算：先算所有长度为 $2$ 的链，再算长度为 $3$ 的链……因为长度为 $r$ 的链依赖长度小于 $r$ 的子链。

```java
void matrixChain(int[] p, int n, int[][] m, int[][] s) {
    for (int i = 1; i <= n; i++) m[i][i] = 0;
    for (int r = 2; r <= n; r++) {              // 区间长度
        for (int i = 1; i <= n - r + 1; i++) {  // 起点
            int j = i + r - 1;                  // 终点
            m[i][j] = m[i + 1][j] + p[i - 1] * p[i] * p[j];
            s[i][j] = i;
            for (int k = i + 1; k < j; k++) {
                int t = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j];
                if (t < m[i][j]) { m[i][j] = t; s[i][j] = k; }
            }
        }
    }
}
```

- 状态数 $O(n^2)$，每个状态枚举 $O(n)$ 个断点，时间 $O(n^3)$；
- 空间 $O(n^2)$（$m$ 与 $s$ 两张表）。

## 5.2.6 算例

设矩阵链为 $A_1A_2A_3A_4A_5A_6$，维数依次为

$$30\times35,\ 35\times15,\ 15\times5,\ 5\times10,\ 10\times20,\ 20\times25$$

即 $p=(30,35,15,5,10,20,25)$。计算得 $m$ 表（只列上三角）：

| $i\backslash j$ | 1 | 2 | 3 | 4 | 5 | 6 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| **1** | 0 | 15750 | 7875 | 9375 | 11875 | **15125** |
| **2** | | 0 | 2625 | 4375 | 7125 | 10500 |
| **3** | | | 0 | 750 | 2500 | 5375 |
| **4** | | | | 0 | 1000 | 3500 |
| **5** | | | | | 0 | 5000 |
| **6** | | | | | | 0 |

对应的断点表 $s$：

| $i\backslash j$ | 1 | 2 | 3 | 4 | 5 | 6 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: |
| **1** | | 1 | 1 | 3 | 3 | **3** |
| **2** | | | 2 | 3 | 3 | 3 |
| **3** | | | | 3 | 3 | 3 |
| **4** | | | | | 4 | 5 |
| **5** | | | | | | 5 |
| **6** | | | | | | |

最优值为 $m[1][6]=15125$。由 $s[1][6]=3$ 知，最优划分是 $(A_1A_2A_3)(A_4A_5A_6)$；继续查表：

- $s[1][3]=1$，左子链为 $A_1(A_2A_3)$；
- $s[4][6]=5$，右子链为 $(A_4A_5)A_6$。

因此最优计算次序为

$$\bigl(A_1(A_2A_3)\bigr)\bigl((A_4A_5)A_6\bigr)$$

::: details 验算
- $A_2A_3$：$35\times15\times5=2625$；
- $A_1(A_2A_3)$：$30\times35\times5=5250$，小计 $7875$；
- $A_4A_5$：$5\times10\times20=1000$；
- $(A_4A_5)A_6$：$5\times20\times25=2500$，小计 $3500$；
- 两部分相乘：$30\times5\times25=3750$。

总计 $7875+3500+3750=15125$，与表中一致。
:::

## 5.2.7 构造最优解

```java
void traceback(int i, int j, int[][] s) {
    if (i == j) return;
    traceback(i, s[i][j], s);
    traceback(s[i][j] + 1, j, s);
    System.out.println("Multiply A" + i + ".." + s[i][j]
                     + " and A" + (s[i][j] + 1) + ".." + j);
}
```

输出顺序是**后序遍历**：先输出左子链的乘法，再输出右子链的乘法，最后输出本次合并。

## 5.2.8 凸多边形最优三角剖分

### 问题描述

给定凸多边形 $P=\{v_0,v_1,\dots,v_{n-1}\}$，以及定义在由多边形的边和弦组成的三角形上的权函数 $w$。要求确定该凸多边形的三角剖分，使得所有三角形权值之和最小。

- **弦**：两个不相邻顶点之间的线段；
- **三角剖分**：将多边形分割成互不相交的三角形的弦的集合 $T$；
- $n$ 个顶点的凸多边形，任何三角剖分都恰有 $n-3$ 条弦、$n-2$ 个三角形。

### 与矩阵连乘的同构

这是本课程最重要的“同构”之一：

| 矩阵连乘 | 凸多边形三角剖分 |
| :--- | :--- |
| 矩阵 $A_i$ | 边 $v_{i-1}v_i$ |
| 子链 $A[i:j]$ | 子多边形 $\{v_{i-1},\dots,v_j\}$ |
| 断点 $k$ | 三角形 $v_{i-1}v_kv_j$ 的顶点 |
| 乘法代价 $p_{i-1}p_kp_j$ | 三角形权值 $w(v_{i-1},v_k,v_j)$ |
| $m[i][j]$ | $t[i][j]$ |

矩阵链乘积的完全加括号方式对应一棵语法树，凸多边形的三角剖分也可以用同一棵语法树表示。**矩阵连乘的最优计算次序问题，就是凸多边形最优三角剖分问题的特殊情形**。

### 递推方程

设 $t[i][j]$ 为凸子多边形 $\{v_{i-1},v_i,\dots,v_j\}$（$1\le i\le j\le n$）的最优三角剖分权值。退化情形 $j=i$ 表示只有一条边，权值为 $0$。

当 $j>i$ 时，子多边形至少有 $3$ 个顶点。设最优剖分包含三角形 $v_{i-1}v_kv_j$（$i\le k\le j-1$），则

$$t[i][j]=\min_{i\le k<j}\Bigl\{t[i][k]+t[k+1][j]+w(v_{i-1},v_k,v_j)\Bigr\}$$

边界：

$$t[i][i]=0,\qquad 1\le i\le n$$

原问题（$(n+1)$ 边形 $v_0v_1\cdots v_n$）的答案为 $t[1][n]$。

```java
void minWeightTriangulation(int n, double[][] w, double[][] t, int[][] s) {
    for (int i = 1; i <= n; i++) t[i][i] = 0;
    for (int r = 2; r <= n; r++)
        for (int i = 1; i <= n - r + 1; i++) {
            int j = i + r - 1;
            t[i][j] = t[i + 1][j] + w(i - 1, i, j);
            s[i][j] = i;
            for (int k = i + 1; k < j; k++) {
                double q = t[i][k] + t[k + 1][j] + w(i - 1, k, j);
                if (q < t[i][j]) { t[i][j] = q; s[i][j] = k; }
            }
        }
}
```

复杂度同样是 $O(n^3)$ 时间、$O(n^2)$ 空间。

::: tip 同构问题的价值
考试中若遇到“多边形剖分”“石子合并”“括号化”“最优二叉搜索树”等看似不同的问题，先不要急着推公式，试着把它们映射到矩阵连乘的框架：

- 是否在**区间**上做划分？
- 划分点是否把区间分成**左右两个子区间**？
- 合并代价是否只与**划分点和区间端点**有关？

若是，递推式几乎可以照搬。
:::
