# 5.3 最长公共子序列及其同构问题

## 5.3.1 问题描述

给定序列 $X=\{x_1,x_2,\dots,x_m\}$，若存在一个严格递增的下标序列 $\{i_1,i_2,\dots,i_k\}$，使得对所有 $j=1,2,\dots,k$ 有 $z_j=x_{i_j}$，则称 $Z=\{z_1,z_2,\dots,z_k\}$ 是 $X$ 的**子序列**。

> 注意：子序列不要求连续，只要求下标递增。子串（substring）才要求连续。

给定两个序列 $X$ 和 $Y$，若 $Z$ 既是 $X$ 的子序列又是 $Y$ 的子序列，则称 $Z$ 是 $X$ 和 $Y$ 的**公共子序列**。长度最长的公共子序列称为**最长公共子序列（LCS）**。

例如：

- $Z=\{B,C,D,B\}$ 是 $X=\{A,B,C,B,D,A,B\}$ 的子序列，对应下标 $\{2,3,5,7\}$；
- $X=\{A,B,C,B,D,A,B\}$，$Y=\{B,D,C,A,B,A\}$，则 $\{B,C,A\}$ 是公共子序列，$\{B,C,B,A\}$ 是最长公共子序列，长度为 $4$。

蛮力法要枚举 $X$ 的所有 $2^m$ 个子序列，逐一检查是否也是 $Y$ 的子序列，复杂度指数级。

## 5.3.2 最优子结构

设 $X=\{x_1,\dots,x_m\}$，$Y=\{y_1,\dots,y_n\}$，$Z=\{z_1,\dots,z_k\}$ 是它们的一个 LCS，则：

1. 若 $x_m=y_n$，则 $z_k=x_m=y_n$，且 $Z_{k-1}$ 是 $X_{m-1}$ 与 $Y_{n-1}$ 的 LCS；
2. 若 $x_m\ne y_n$ 且 $z_k\ne x_m$，则 $Z$ 是 $X_{m-1}$ 与 $Y$ 的 LCS；
3. 若 $x_m\ne y_n$ 且 $z_k\ne y_n$，则 $Z$ 是 $X$ 与 $Y_{n-1}$ 的 LCS。

::: details 证明思路
- 情形 1：若 $z_k\ne x_m$，则可以把 $x_m$ 接在 $Z$ 后面得到更长的公共子序列，矛盾；故 $z_k=x_m=y_n$。又若 $Z_{k-1}$ 不是 $X_{m-1},Y_{n-1}$ 的 LCS，替换成更长的后接上 $x_m$ 会得到更长的公共子序列，矛盾。
- 情形 2：若 $Z$ 不是 $X_{m-1},Y$ 的 LCS，则存在更长的公共子序列，它也是 $X,Y$ 的公共子序列，矛盾。
- 情形 3 对称。
:::

由此可见，两个序列的 LCS 包含了它们**前缀**的 LCS，满足最优子结构。

## 5.3.3 递推方程

设 $c[i][j]$ 为前缀 $X_i=\{x_1,\dots,x_i\}$ 与 $Y_j=\{y_1,\dots,y_j\}$ 的 LCS 长度。当 $i=0$ 或 $j=0$ 时，空序列是唯一的公共子序列，故 $c[i][0]=c[0][j]=0$。于是

$$c[i][j]=\begin{cases}
0, & i=0\ \text{或}\ j=0\\[4pt]
c[i-1][j-1]+1, & i,j>0\ \text{且}\ x_i=y_j\\[4pt]
\max\bigl\{c[i-1][j],\ c[i][j-1]\bigr\}, & i,j>0\ \text{且}\ x_i\ne y_j
\end{cases}$$

## 5.3.4 计算最优值

```java
void lcsLength(int m, int n, char[] x, char[] y, int[][] c, int[][] b) {
    for (int i = 1; i <= m; i++) c[i][0] = 0;
    for (int j = 1; j <= n; j++) c[0][j] = 0;
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++) {
            if (x[i] == y[j]) {
                c[i][j] = c[i - 1][j - 1] + 1;
                b[i][j] = 1;                  // 左上
            } else if (c[i - 1][j] >= c[i][j - 1]) {
                c[i][j] = c[i - 1][j];
                b[i][j] = 2;                  // 上
            } else {
                c[i][j] = c[i][j - 1];
                b[i][j] = 3;                  // 左
            }
        }
}
```

- 子问题总数 $\Theta(mn)$，每个 $O(1)$，时间 $O(mn)$；
- 空间 $O(mn)$；若只求长度，可把二维滚动成一维，空间降到 $O(\min(m,n))$。

### 算例

$X=\{A,B,C,B,D,A,B\}$，$Y=\{B,D,C,A,B,A\}$，$c$ 表为：

| $i\backslash j$ | 0 | 1 B | 2 D | 3 C | 4 A | 5 B | 6 A |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **0** | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| **1 A** | 0 | 0 | 0 | 0 | 1 | 1 | 1 |
| **2 B** | 0 | 1 | 1 | 1 | 1 | 2 | 2 |
| **3 C** | 0 | 1 | 1 | 2 | 2 | 2 | 2 |
| **4 B** | 0 | 1 | 1 | 2 | 2 | 3 | 3 |
| **5 D** | 0 | 1 | 2 | 2 | 2 | 3 | 3 |
| **6 A** | 0 | 1 | 2 | 2 | 3 | 3 | 4 |
| **7 B** | 0 | 1 | 2 | 2 | 3 | 4 | 4 |

右下角 $c[7][6]=4$，即 LCS 长度为 $4$。

## 5.3.5 构造最优解

从 $b[m][n]$ 开始回溯：

- $b[i][j]=1$：$x_i=y_j$，该字符属于 LCS，走向左上 $(i-1,j-1)$；
- $b[i][j]=2$：走向上 $(i-1,j)$；
- $b[i][j]=3$：走向左 $(i,j-1)$。

```java
void lcs(int i, int j, char[] x, int[][] b) {
    if (i == 0 || j == 0) return;
    if (b[i][j] == 1) {
        lcs(i - 1, j - 1, x, b);
        System.out.print(x[i]);
    } else if (b[i][j] == 2) {
        lcs(i - 1, j, x, b);
    } else {
        lcs(i, j - 1, x, b);
    }
}
```

回溯路径长度 $O(m+n)$，因此构造最优解的时间是 $O(m+n)$。

::: tip LCS 不唯一
当 $x_i\ne y_j$ 且 $c[i-1][j]=c[i][j-1]$ 时，向上或向左都能得到最优解。上面的代码用 `>=` 统一选择“向上”，因此输出的是其中一个 LCS（本例为 `BCBA`）。若要输出所有 LCS，需要保留两条路径并回溯搜索。
:::

## 5.3.6 同构问题一：最长单调递增子序列

问题：设 $L=\{a_1,a_2,\dots,a_n\}$ 是 $n$ 个不同实数的序列，求最长的递增子序列长度。

设 $d[i]$ 为以 $a_i$ **结尾**的最长递增子序列长度，则

$$d[i]=\max_{0\le k<i,\ a_k<a_i}\bigl\{d[k]\bigr\}+1,\qquad d[0]=1$$

答案为 $\max_i d[i]$。时间 $O(n^2)$，空间 $O(n)$。

::: info 与 LCS 的关系
若把原序列排序得到 $L'$，则 $L$ 与 $L'$ 的 LCS 就是最长递增子序列——这是 LIS 与 LCS 的同构。但由于 LCS 是 $O(n^2)$，这个转化并不更优。利用贪心 + 二分（耐心排序）可以把 LIS 降到 $O(n\log n)$。
:::

## 5.3.7 同构问题二：序列匹配

问题：设 $S_1[1..m]$ 和 $S_2[1..n]$ 为两个字符序列，允许在任一序列中插入空格使它们对齐。对齐规则：

- 两个对应字符相等，权值 $+2$；
- 两个对应字符不等，权值 $-2$；
- 一个字符对一个空格，权值 $-1$。

求权值最大的对齐方式（匹配度）。

设 $c[i][j]$ 为 $S_1[1..i]$ 与 $S_2[1..j]$ 的最大匹配权值，$t(x,y)$ 为字符 $x,y$ 对齐的权值，则

$$c[i][j]=\max\begin{cases}
c[i-1][j-1]+t(S_1[i],S_2[j])\\
c[i-1][j]-1\\
c[i][j-1]-1
\end{cases}$$

其中

$$t(x,y)=\begin{cases}+2, & x=y\\-2, & x\ne y\end{cases}$$

边界取 $c[i][0]=c[0][j]=0$（课件约定，允许局部最优对齐；若要求全局对齐，应初始化为 $-i$ 与 $-j$）。

以 $S_1=\text{axabcdes}$、$S_2=\text{axbacfes}$ 为例，一种最优对齐为：

```text
a x a b - c d e s
a x - b a c f e s
```

匹配 $6$ 对（$+12$），两个字符对空格（$-2$），一对失配（$-2$），总权值 $8$。时间复杂度 $O(mn)$。

::: tip 与 LCS 的统一视角
把“匹配”看作“对齐”，把“空格”看作“删除/插入”，LCS、编辑距离、序列比对本质上都是**双序列对齐问题**，只是权值定义不同：

| 问题 | 匹配 | 失配 | 空格 |
| :--- | :--- | :--- | :--- |
| LCS | $+1$ | 不可 | $0$（跳过） |
| 编辑距离 | $0$ | $+1$ | $+1$ |
| 序列比对 | $+2$ | $-2$ | $-1$ |

记住这个框架，遇到新变体只需改权值。
:::

## 5.3.8 同构问题三：电路布线

问题：在一块电路板的上、下两端分别有 $n$ 个接线柱，用导线 $(i,\pi(i))$ 将上端第 $i$ 个接线柱与下端第 $\pi(i)$ 个接线柱相连，其中 $\pi$ 是 $\{1,2,\dots,n\}$ 的一个排列。要求选出尽可能多的导线，使它们**互不相交**。

两条导线 $(i,\pi(i))$ 与 $(j,\pi(j))$（$i<j$）相交的充要条件是

$$\pi(i)>\pi(j)$$

因此问题等价于：在排列 $\pi$ 中选出最长的、下标与值都递增的子序列——这正是 LCS 的变体。

设 $N(i,j)=\{(t,\pi(t))\mid 1\le t\le i,\ \pi(t)\le j\}$，$\text{Size}(i,j)$ 为其最大不相交子集的大小，则

$$\text{Size}(1,j)=\begin{cases}0, & j<\pi(1)\\1, & j\ge\pi(1)\end{cases}$$

$$\text{Size}(i,j)=\begin{cases}
\text{Size}(i-1,j), & j<\pi(i)\\
\max\bigl\{\text{Size}(i-1,j),\ \text{Size}(i-1,\pi(i)-1)+1\bigr\}, & j\ge\pi(i)
\end{cases}$$

```java
void mns(int[] c, int n, int[][] size) {
    for (int j = 0; j < c[1]; j++) size[1][j] = 0;
    for (int j = c[1]; j <= n; j++) size[1][j] = 1;
    for (int i = 2; i < n; i++) {
        for (int j = 0; j < c[i]; j++) size[i][j] = size[i - 1][j];
        for (int j = c[i]; j <= n; j++)
            size[i][j] = Math.max(size[i - 1][j], size[i - 1][c[i] - 1] + 1);
    }
    size[n][n] = Math.max(size[n - 1][n], size[n - 1][c[n] - 1] + 1);
}
```

时间 $O(n^2)$，空间 $O(n^2)$，回溯构造方案 $O(n)$。

::: info 同构识别的意义
矩阵连乘、凸多边形剖分、最优 BST 是“区间划分”同构；LCS、LIS、序列比对、电路布线是“双序列对齐”同构。考试中见到新问题，先判断它属于哪一族，再套用相应的递推框架，比从零推导快得多。
:::
