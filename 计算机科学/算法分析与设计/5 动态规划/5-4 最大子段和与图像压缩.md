# 5.4 最大子段和与图像压缩

## 5.4.1 最大子段和问题

问题：给定 $n$ 个整数（可能为负）组成的序列 $(a_1,a_2,\dots,a_n)$，求形如

$$\sum_{k=i}^{j}a_k,\qquad 1\le i\le j\le n$$

的子段和的最大值。当所有整数均为负数时，定义最大子段和为 $0$（即允许空子段）。

例如 $A=(-2,11,-4,13,-5,-2)$：

| 子段长度 | 各子段和 | 最大值 |
| :--- | :--- | ---: |
| 1 | $-2,11,-4,13,-5,-2$ | 13 |
| 2 | $9,7,9,8,-7$ | 9 |
| 3 | $5,20,4,6$ | 20 |
| 4 | $18,15,2$ | 18 |
| 5 | $13,13$ | 13 |
| 6 | $11$ | 11 |

最大子段和为 $11-4+13=20$，对应子段 $a_2..a_4$。

### 蛮力法

三重循环枚举 $i,j$ 并求和，$O(n^3)$；固定 $i$、边扩展 $j$ 边累加，$O(n^2)$。

```java
int maxSum(int[] a, int n) {
    int sum = 0;
    for (int i = 1; i <= n; i++) {
        int thisSum = 0;
        for (int j = i; j <= n; j++) {
            thisSum += a[j];
            if (thisSum > sum) sum = thisSum;
        }
    }
    return sum;
}
```

### 分治法

把序列从中间 $center$ 分成左右两半：

1. 递归求左半的最大子段和 $leftSum$；
2. 递归求右半的最大子段和 $rightSum$；
3. 求跨越中点的最大子段和：从 $center$ 向左累加得到最大和 $s_1$，从 $center+1$ 向右累加得到最大和 $s_2$，跨中点最大和为 $s_1+s_2$；
4. 答案为 $\max\{leftSum,rightSum,s_1+s_2\}$。

```java
int maxSubSum(int[] a, int left, int right) {
    if (left == right) return Math.max(a[left], 0);
    int center = (left + right) / 2;
    int leftSum = maxSubSum(a, left, center);
    int rightSum = maxSubSum(a, center + 1, right);
    int s1 = 0, lefts = 0;
    for (int i = center; i >= left; i--) {
        lefts += a[i];
        if (lefts > s1) s1 = lefts;
    }
    int s2 = 0, rights = 0;
    for (int i = center + 1; i <= right; i++) {
        rights += a[i];
        if (rights > s2) s2 = rights;
    }
    return Math.max(Math.max(leftSum, rightSum), s1 + s2);
}
```

递推式

$$T(n)=2T\left(\frac{n}{2}\right)+O(n)\quad\Longrightarrow\quad T(n)=O(n\log n)$$

### 动态规划

设 $b[j]$ 为**以 $a_j$ 结尾**的最大子段和，则

$$b[j]=\max\bigl\{b[j-1]+a[j],\ a[j]\bigr\},\qquad b[1]=a[1]$$

答案为 $\max_{1\le j\le n}b[j]$（若允许空子段，则再与 $0$ 取最大）。

```java
int maxSum(int[] a, int n) {
    int sum = 0, b = 0;
    for (int i = 1; i <= n; i++) {
        b = (b > 0) ? b + a[i] : a[i];
        if (b > sum) sum = b;
    }
    return sum;
}
```

时间 $O(n)$，空间 $O(1)$。

::: details 为什么 $b[j]$ 的定义是关键？
如果定义 $dp[j]$ 为“前 $j$ 个元素中的最大子段和”，则 $dp[j]$ 与 $dp[j-1]$ 之间没有直接的递推关系，因为 $a_j$ 可能接上前面，也可能不接。

改为“**以 $a_j$ 结尾**”后，决策只有两个：接上前面的（$b[j-1]+a[j]$），或从 $a_j$ 重新开始（$a[j]$）。这就是无后效性：只要知道“以 $a_j$ 结尾的最大和”，后面的决策就足够了。
:::

### 追踪具体子段

```java
int bestSum = 0, bestI = 0, bestJ = 0;
int b = 0, start = 1;
for (int j = 1; j <= n; j++) {
    if (b > 0) b += a[j];
    else { b = a[j]; start = j; }
    if (b > bestSum) { bestSum = b; bestI = start; bestJ = j; }
}
```

### 三种方法对比

| 方法 | 时间 | 空间 | 特点 |
| :--- | :--- | :--- | :--- |
| 蛮力（三重循环） | $O(n^3)$ | $O(1)$ | 最直观 |
| 蛮力（前缀和） | $O(n^2)$ | $O(1)$ | 固定起点累加 |
| 分治 | $O(n\log n)$ | $O(\log n)$ | 体现分治思想 |
| 动态规划 | $O(n)$ | $O(1)$ | 最优，代码最短 |

## 5.4.2 图像压缩问题

### 问题描述

图像的变位压缩存储格式，将像素点序列 $\{p_1,p_2,\dots,p_n\}$（$0\le p_i\le255$）分割成 $m$ 个连续段 $S_1,S_2,\dots,S_m$。第 $i$ 段 $S_i$ 有 $l[i]$ 个像素，每个像素只用 $b[i]$ 位表示。

设

$$h_i=\left\lceil\log_2\left(\max_{t[i-1]<k\le t[i]}p_k+1\right)\right\rceil$$

其中 $t[i]=\sum_{k=1}^{i}l[k]$ 是前 $i$ 段的总像素数。则 $h_i\le b[i]\le8$。

段头需要记录 $b[i]$ 与 $l[i]$：$b[i]\in[0,8]$ 用 $3$ 位，$l[i]\in[1,255]$ 用 $8$ 位，共 **$11$ 位**。因此第 $i$ 段占用

$$l[i]\times b[i]+11 \quad\text{位}$$

总存储量为

$$\sum_{i=1}^{m}\bigl(l[i]\cdot b[i]+11\bigr)$$

目标：确定最优分段，使总位数最少。

### 一个例子

设 $P=\{10,12,15,255,1,2,1,1,2,2,1,1\}$。各像素所需位数：

| 像素 | 10 | 12 | 15 | 255 | 1 | 2 | 1 | 1 | 2 | 2 | 1 | 1 |
| :--- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 位数 | 4 | 4 | 4 | 8 | 1 | 2 | 1 | 1 | 2 | 2 | 1 | 1 |

不同划分的代价：

- $S_1=\{10,12,15\}$，$S_2=\{255\}$，$S_3=\{1,2,1,1,2,2,1,1\}$：$3\times4+11+1\times8+11+8\times2+11=69$；
- 全部 12 个像素一段：$12\times8+11=107$；
- 每个像素单独一段：$3\times(4+11)+(8+11)+4\times(1+11)+4\times(2+11)=164$。

可见分段方式对压缩效果影响很大。

### 最优子结构

设 $l[i],b[i]$（$1\le i\le m$）是 $\{p_1,\dots,p_n\}$ 的一个最优分段，则：

- $l[1],b[1]$ 是 $\{p_1,\dots,p_{l[1]}\}$ 的最优分段；
- $l[i],b[i]$（$2\le i\le m$）是 $\{p_{l[1]+1},\dots,p_n\}$ 的最优分段。

否则替换为更优的分段会得到整体更优，矛盾。

### 递推方程

设 $s[i]$ 为前 $i$ 个像素的最优分段所需位数，则

$$s[i]=\min_{1\le k\le\min(i,256)}\Bigl\{s[i-k]+k\cdot \text{bmax}(i-k+1,i)\Bigr\}+11,\qquad s[0]=0$$

其中 $\text{bmax}(i-k+1,i)$ 是第 $i-k+1$ 到第 $i$ 个像素中最大像素所需的位数，即该段每个像素的存储位数。

```java
int length(int i) {          // 表示 i 所需的最少二进制位数
    int k = 1;
    i = i / 2;
    while (i > 0) { k++; i = i / 2; }
    return k;
}

void compress(int n, int[] p, int[] s, int[] l, int[] b) {
    int Lmax = 256, header = 11;
    s[0] = 0;
    for (int i = 1; i <= n; i++) {
        b[i] = length(p[i]);
        int bmax = b[i];
        s[i] = s[i - 1] + bmax;      // 先假设单独成段
        l[i] = 1;
        for (int j = 2; j <= i && j <= Lmax; j++) {
            if (bmax < b[i - j + 1]) bmax = b[i - j + 1];
            if (s[i] > s[i - j] + j * bmax) {
                s[i] = s[i - j] + j * bmax;
                l[i] = j;
            }
        }
        s[i] += header;
    }
}
```

### 复杂度

内层循环最多执行 $256$ 次（分段长度不超过 $255$ 个像素，加上初值），是常数。因此每个 $i$ 的计算是 $O(1)$，总时间

$$T(n)=O(n)$$

空间 $O(n)$。这看似不可思议：一个看起来需要枚举所有分段的问题，竟然能线性时间求解。原因在于**分段长度有常数上界**，把原本的 $O(n^2)$ 枚举压缩成了常数窗口。

### 构造最优解

用 $l[i]$ 记录“以 $i$ 结尾的最后一段长度”，从 $n$ 向前回溯：

```java
void traceback(int n, int[] s, int[] l) {
    if (n == 0) return;
    traceback(n - l[n], s, l);
    // 此时可输出分段 [n-l[n]+1, n]
}
```

### 算例

设 $P=\{10,12,15,255,1,2\}$：

| $i$ | $s[i]$ | $l[i]$ | 说明 |
| ---: | ---: | ---: | :--- |
| 0 | 0 | — | 边界 |
| 1 | 15 | 1 | $\{10\}$：$4+11$ |
| 2 | 19 | 2 | $\{10,12\}$：$2\times4+11$ |
| 3 | 23 | 3 | $\{10,12,15\}$：$3\times4+11$ |
| 4 | 42 | 1 | $\{10,12,15\},\{255\}$：$23+8+11$ |
| 5 | 50 | 2 | $\{10,12,15\},\{255,1\}$：$23+2\times8+11$ |
| 6 | 57 | 2 | $\{10,12,15\},\{255\},\{1,2\}$：$42+2\times2+11$ |

最优划分为 $\{10,12,15\}$、$\{255\}$、$\{1,2\}$，总位数 $57$。

::: tip 图像压缩的启示
动态规划的“状态”未必要以“元素个数”为唯一维度。本题的状态是 $s[i]$（前 $i$ 个像素的最优值），但转移时枚举的是“最后一段的长度”。这种“**以结尾为状态、以最后一段为决策**”的模式，在字符串分割、单词拆分、邮局选址等问题中反复出现。
:::
