# 2.2 函数的渐近界

比较两个算法时，我们真正关心的不是“在 $n=10$ 时谁快 0.3 毫秒”，而是“当 $n$ 不断增大时，谁的增长更慢”。这种“只看增长趋势、忽略常数与低阶项”的比较工具，就是**渐近记号**。

## 2.2.1 五个记号的定义

设 $f$ 和 $g$ 是定义在自然数集上的非负函数（$g$ 最终为正）。

| 记号 | 读法 | 形式定义 | 直观含义 |
| :--- | :--- | :--- | :--- |
| $f(n)=O(g(n))$ | 大 O | $\exists c>0,\, n_0,\ \forall n\ge n_0:\ 0\le f(n)\le c\,g(n)$ | $f$ 增长**不快于** $g$ |
| $f(n)=\Omega(g(n))$ | 大 Omega | $\exists c>0,\, n_0,\ \forall n\ge n_0:\ 0\le c\,g(n)\le f(n)$ | $f$ 增长**不慢于** $g$ |
| $f(n)=\Theta(g(n))$ | 大 Theta | $f=O(g)$ 且 $f=\Omega(g)$ | $f$ 与 $g$ **同阶** |
| $f(n)=o(g(n))$ | 小 o | $\forall c>0,\ \exists n_0,\ \forall n\ge n_0:\ 0\le f(n)<c\,g(n)$ | $f$ 增长**严格慢于** $g$ |
| $f(n)=\omega(g(n))$ | 小 omega | $\forall c>0,\ \exists n_0,\ \forall n\ge n_0:\ 0\le c\,g(n)<f(n)$ | $f$ 增长**严格快于** $g$ |

::: warning “等号”不是等号
$f(n)=O(g(n))$ 中的“$=$”只是一种传统写法，读作“$f$ 属于 $O(g)$ 这个函数类”。它不满足对称性：$n=O(n^2)$ 成立，但 $n^2=O(n)$ 不成立。写作业时不要做“两边同除”之类的代数变形。
:::

::: details 用图理解 $O$ 与 $\Theta$
$f(n)=O(g(n))$ 表示：存在一条过原点的直线 $y=c\,g(n)$，当 $n$ 足够大（$n\ge n_0$）后，$f$ 的图像始终压在这条直线下方。

$f(n)=\Theta(g(n))$ 表示：存在两条直线 $c_1 g(n)$ 与 $c_2 g(n)$，当 $n\ge n_0$ 后，$f$ 的图像被夹在两条直线之间。**$n_0$ 之前发生什么无关紧要**，这正是“渐近”二字的含义。
:::

## 2.2.2 用极限判断阶

当 $g(n)>0$ 且极限存在时，计算

$$L=\lim_{n\to\infty}\frac{f(n)}{g(n)}$$

有：

| 极限 $L$ | 结论 |
| :--- | :--- |
| $L=0$ | $f(n)=o(g(n))$，从而 $f=O(g)$ |
| $0<L<\infty$ | $f(n)=\Theta(g(n))$ |
| $L=\infty$ | $f(n)=\omega(g(n))$，从而 $f=\Omega(g)$ |

这是做题最快的工具。例如：

$$\lim_{n\to\infty}\frac{3n^2+2n}{n^2}=3 \quad\Rightarrow\quad 3n^2+2n=\Theta(n^2)$$

$$\lim_{n\to\infty}\frac{\log n}{n^{0.1}}=0 \quad\Rightarrow\quad \log n=o(n^{0.1})$$

## 2.2.3 基本性质

**传递性**：

$$f=O(g),\ g=O(h)\ \Rightarrow\ f=O(h)$$

对 $\Omega$、$\Theta$、$o$、$\omega$ 同样成立。

**加法规则**：

$$O(f(n))+O(g(n))=O\bigl(\max\{f(n),g(n)\}\bigr)=O\bigl(f(n)+g(n)\bigr)$$

即“多项相加，取增长最快的一项”。

**乘法规则**：

$$O(f(n))\cdot O(g(n))=O\bigl(f(n)g(n)\bigr)$$

::: tip 这些规则怎么用
分析一段“先做 $O(n^2)$ 的初始化，再做 $O(n\log n)$ 的排序”的代码，总复杂度是 $O(n^2)+O(n\log n)=O(n^2)$。分析“外层 $n$ 次循环、内层 $O(\log n)$”的代码，总复杂度是 $O(n)\cdot O(\log n)=O(n\log n)$。
:::

## 2.2.4 几个必须会证的结论

### 多项式函数

设

$$f(n)=a_0+a_1 n+a_2 n^2+\cdots+a_d n^d,\qquad a_d\neq 0$$

则 $f(n)=\Theta(n^d)$。

::: details 证明
当 $n\ge 1$ 时，

$$|f(n)|\le |a_0|+|a_1|n+\cdots+|a_d|n^d\le \bigl(|a_0|+|a_1|+\cdots+|a_d|\bigr)n^d$$

取 $c_2=|a_0|+\cdots+|a_d|$，得 $f(n)\le c_2 n^d$，即 $f=O(n^d)$。

另一方面，当 $n$ 足够大时，$|a_d|n^d$ 会超过其余项绝对值之和，于是存在 $c_1>0$ 使 $f(n)\ge c_1 n^d$，即 $f=\Omega(n^d)$。两者合起来得 $f=\Theta(n^d)$。
:::

### 对数换底

对任意 $a,b>1$，

$$\log_a n=\frac{\log_b n}{\log_b a}=\Theta(\log_b n)$$

因此**对数的底数在渐近意义下不重要**，算法分析中常直接写 $\log n$。

### 对数、幂、指数、阶乘的层级

对 $b>1$ 与 $\alpha>0$：

$$\log_b n=o(n^{\alpha}),\qquad n^{\alpha}=o(b^{n})$$

也就是说：

$$\log n \ \prec\ n^{\alpha}\ \prec\ b^{n}$$

此外，

$$n!=o(n^n),\qquad n!=\omega(2^n),\qquad \log(n!)=\Theta(n\log n)$$

::: details $\log(n!)=\Theta(n\log n)$ 的证明
由 Stirling 公式 $n!\sim\sqrt{2\pi n}\,(n/e)^n$，取对数得

$$\log(n!)=\Theta(n\log n)$$

也可以用夹逼：一方面 $n!\le n^n$ 给出 $\log(n!)\le n\log n$；另一方面只取后一半因子，

$$n!\ge \left(\frac{n}{2}\right)^{n/2}\ \Rightarrow\ \log(n!)\ge \frac{n}{2}\log\frac{n}{2}=\Theta(n\log n)$$
:::

## 2.2.5 常见渐近效率类型

| 阶 | 名称 | 典型算法 | $n=10^6$ 时的量级（约） |
| :--- | :--- | :--- | :--- |
| $1$ | 常量 | 数组随机访问、散列查找 | $1$ |
| $\log n$ | 对数 | 二分查找 | $20$ |
| $n$ | 线性 | 顺序查找、找最大值 | $10^6$ |
| $n\log n$ | 线性对数 | 归并排序、快速排序（平均）、堆排序 | $2\times 10^7$ |
| $n^2$ | 平方 | 选择排序、冒泡排序、点对距离 | $10^{12}$ |
| $n^3$ | 立方 | 矩阵乘法（朴素）、Floyd | $10^{18}$ |
| $2^n$ | 指数 | 枚举所有子集、汉诺塔 | 天文数字 |
| $n!$ | 阶乘 | 枚举所有排列、TSP 蛮力 | 天文数字 |

::: warning 指数级算法只能处理很小的规模
假设机器每秒执行 $10^9$ 次运算：

- $n=50$ 时，$2^n\approx 1.1\times 10^{15}$，需要约 $13$ 天；
- $n=60$ 时，$2^n\approx 1.15\times 10^{18}$，需要约 $36$ 年；
- $n=20$ 时，$20!\approx 2.4\times 10^{18}$，同样需要数十年。

这就是为什么 NP 难问题必须借助剪枝、近似或启发式算法。
:::

## 2.2.6 易错点清单

1. **$O$ 是上界，不一定是紧界**。$n=O(n^2)$ 正确，但我们通常写更紧的 $O(n)$。
2. **$\Theta$ 才表示同阶**。说“快速排序最坏是 $O(n^2)$”没错，但若说“是 $\Theta(n^2)$”则需要指出这是最坏情况。
3. **常数可以忽略，但不能为负**。渐近记号默认函数非负。
4. **指数不能随便“降维”**：$2^{2n}\neq O(2^n)$，因为比值为 $2^n\to\infty$。
5. **对数底数可忽略**，但 $\log^2 n$ 与 $\log n$ 不同阶。
6. **多参数问题**要保留多个变量，如矩阵乘法 $O(mnk)$，不能简单写成 $O(n^3)$。
7. **递归式的解**要说明边界条件，如 $T(1)=O(1)$。
