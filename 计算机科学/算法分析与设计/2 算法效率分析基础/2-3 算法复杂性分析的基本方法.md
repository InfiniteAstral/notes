# 2.3 算法复杂性分析的基本方法

有了渐近记号这把尺子，接下来要解决“怎么量”的问题。对非递归算法，量的是**基本操作的执行次数**，本质是求和；对递归算法，量的是**递推关系**，本质是解方程。

## 2.3.1 分析的五步法

1. **确定表示输入规模的参数**。数组用元素个数 $n$，矩阵用阶数 $n$，图用顶点数 $n$ 与边数 $m$，整数用二进制位数。
2. **找出算法的基本操作**。通常是循环最内层、执行最频繁的那条语句，如比较、乘法、赋值。
3. **检查基本操作的执行次数是否只依赖于输入规模**。若还依赖具体输入（如查找中元素的位置），就必须分最好、最坏、平均讨论。
4. **建立表达式**。非递归算法列求和式；递归算法列递推方程并给出初始条件。
5. **求解并确定阶**。用求和公式、递推求解或主定理，写出 $O,\Omega,\Theta$。

## 2.3.2 常用求和公式

$$\sum_{k=1}^{n} k=\frac{n(n+1)}{2}=O(n^2)$$

$$\sum_{k=1}^{n} k^2=\frac{n(n+1)(2n+1)}{6}=O(n^3)$$

$$\sum_{k=0}^{n} q^k=\frac{1-q^{n+1}}{1-q}\quad(q\neq 1),\qquad \sum_{k=0}^{n} 2^k=2^{n+1}-1$$

$$\sum_{k=1}^{n}\frac{1}{k}=\ln n+O(1)=O(\log n)$$

$$\sum_{k=1}^{n}\log k=\log(n!)=\Theta(n\log n)$$

::: tip 看见“双层循环”先别急着写 $O(n^2)$
内层循环的起点、终点、步长决定了求和上下限。例如

```text
for i ← 1 to n
    for j ← i to n
```

的执行次数是 $\sum_{i=1}^{n}(n-i+1)=n+(n-1)+\cdots+1=\dfrac{n(n+1)}{2}$，仍是 $O(n^2)$，但系数是 $1/2$。若内层是 `j ← i to n step i`，则总次数为 $n\log n$ 量级。
:::

## 2.3.3 非递归算法：从代码到求和式

### 例 1：求数组最大值

```text
maxElement(A[0..n-1])
maxval ← A[0]
for i ← 1 to n-1
    if A[i] > maxval
        maxval ← A[i]
return maxval
```

- 规模：$n$；
- 基本操作：比较 `A[i] > maxval`；
- 比较次数与元素取值无关，恒为 $n-1$；
- 因此 $T(n)=n-1=\Theta(n)$。

### 例 2：判断元素是否全部唯一

```text
uniqueElements(A[0..n-1])
for i ← 0 to n-2
    for j ← i+1 to n-1
        if A[i] = A[j] return false
return true
```

最坏情况（元素全部互异，或重复出现在最后）比较次数为

$$T_{\max}(n)=\sum_{i=0}^{n-2}\sum_{j=i+1}^{n-1}1=\sum_{i=0}^{n-2}(n-1-i)=\frac{n(n-1)}{2}=\Theta(n^2)$$

最好情况是第一对就比较出相等，$T_{\min}(n)=O(1)$。

::: info 平均情况怎么分析？
平均效率取决于**元素取值的分布**：

- 若数组是 $n$ 个**互不相同**元素的随机排列，则永远不会提前返回，$T_{\text{avg}}(n)=\Theta(n^2)$；
- 若元素从大小为 $m$ 的集合中均匀独立抽取，则任意一对相等的概率为 $1/m$，期望比较次数约为 $\dfrac{n(n-1)}{2m}$。当 $m$ 与 $n$ 同阶时，平均只需 $O(n)$ 次比较。

可见“平均”不是算法固有的属性，而是**算法 + 输入分布**共同的属性。
:::

### 例 3：插入排序

```cpp
void insertion_sort(Type *a, int n) {
    Type key;                          // cost  times
    for (int i = 1; i < n; i++) {      // c1    n
        key = a[i];                    // c2    n-1
        int j = i - 1;                 // c3    n-1
        while (j >= 0 && a[j] > key) { // c4    sum t_i
            a[j+1] = a[j];             // c5    sum(t_i - 1)
            j--;                       // c6    sum(t_i - 1)
        }
        a[j+1] = key;                  // c7    n-1
    }
}
```

设第 $i$ 轮 `while` 的比较次数为 $t_i$，则

$$T(n)=c_1n+c_2(n-1)+c_3(n-1)+c_4\sum_{i=1}^{n-1}t_i+c_5\sum_{i=1}^{n-1}(t_i-1)+c_6\sum_{i=1}^{n-1}(t_i-1)+c_7(n-1)$$

- **最好情况**：数组已升序，$t_i=1$，所有求和项都是 $O(n)$，故 $T_{\min}(n)=\Theta(n)$；
- **最坏情况**：数组降序，$t_i=i+1$，$\sum t_i=\Theta(n^2)$，故 $T_{\max}(n)=\Theta(n^2)$；
- **平均情况**：$t_i\approx i/2$，仍是 $\Theta(n^2)$。

### 例 4：方阵乘法与二进制位数

```text
for i ← 0 to n-1
    for j ← 0 to n-1
        M[i][j] ← 0
        for k ← 0 to n-1
            M[i][j] ← M[i][j] + A[i][k] * B[k][j]
```

三重循环各执行 $n$ 次，乘法 $n^3$ 次、加法 $n^2(n-1)$ 次，$T(n)=\Theta(n^3)$。

```text
binary(n)
count ← 1
while n > 1
    count ← count + 1
    n ← n / 2        // 整除
return count
```

每轮 $n$ 减半，循环执行 $\lfloor\log_2 n\rfloor$ 次，$T(n)=\Theta(\log n)$。

## 2.3.4 递归算法：两类典型递推

### 类型一：规模线性递减

$$T(n)=aT(n-1)+f(n),\qquad T(1)=O(1)$$

展开递推：

$$T(n)=a^{n-1}T(1)+\sum_{i=2}^{n}a^{n-i}f(i)$$

**汉诺塔**（$a=2,\ f(n)=1$）：

$$T(n)=2T(n-1)+1=2^{n}-1=\Theta(2^n)$$

**插入排序最坏情况**（$a=1,\ f(n)=n-1$）：

$$T(n)=T(n-1)+(n-1)=\sum_{i=1}^{n-1}i=\frac{n(n-1)}{2}=\Theta(n^2)$$

### 类型二：规模按比例递减

$$T(n)=aT\left(\frac{n}{b}\right)+f(n),\qquad T(1)=O(1)$$

设 $n=b^k$，逐层展开得

$$T(n)=a^{k}T(1)+\sum_{j=0}^{k-1}a^{j}f\left(\frac{n}{b^{j}}\right),\qquad k=\log_b n$$

对两类常见的 $f$ 有现成结论：

**（1）$f(n)=c$（常数）**

$$T(n)=\begin{cases}\Theta\left(n^{\log_b a}\right), & a>1\\[4pt] \Theta(\log n), & a=1\end{cases}$$

**（2）$f(n)=cn$（线性）**

$$T(n)=\begin{cases}\Theta(n), & a<b\\[4pt] \Theta(n\log n), & a=b\\[4pt] \Theta\left(n^{\log_b a}\right), & a>b\end{cases}$$

::: details 主定理（Master Theorem）
对 $T(n)=aT(n/b)+f(n)$，$a\ge 1,\ b>1$，比较 $f(n)$ 与 $n^{\log_b a}$：

1. 若 $f(n)=O\left(n^{\log_b a-\varepsilon}\right)$（$\varepsilon>0$），则 $T(n)=\Theta\left(n^{\log_b a}\right)$；
2. 若 $f(n)=\Theta\left(n^{\log_b a}\right)$，则 $T(n)=\Theta\left(n^{\log_b a}\log n\right)$；
3. 若 $f(n)=\Omega\left(n^{\log_b a+\varepsilon}\right)$，且存在 $c<1$ 使 $a f(n/b)\le c f(n)$（正则条件），则 $T(n)=\Theta(f(n))$。

直观记忆：**谁大听谁的**。子问题总代价 $n^{\log_b a}$ 更大，取它；合并代价 $f(n)$ 更大，取它；两者相当，乘一个 $\log n$。
:::

### 例 5：四个必须记住的结果

| 递推式 | 对应算法 | 解 |
| :--- | :--- | :--- |
| $T(n)=T(n/2)+O(1)$ | 二分查找 | $\Theta(\log n)$ |
| $T(n)=2T(n/2)+O(n)$ | 归并排序、快速排序（平均） | $\Theta(n\log n)$ |
| $T(n)=T(n-1)+O(1)$ | 插入排序（最好） | $\Theta(n)$ |
| $T(n)=T(n-1)+O(n)$ | 插入排序（最坏） | $\Theta(n^2)$ |

### 例 6：递归树法

对

$$T(n)=T\left(\frac{n}{3}\right)+T\left(\frac{2n}{3}\right)+n,\qquad T(1)=O(1)$$

画递归树：根结点代价 $n$，两个子结点代价之和 $\dfrac{n}{3}+\dfrac{2n}{3}=n$，下一层仍是 $n$……每一层的总代价都是 $n$。树的最深路径沿 $2n/3$ 分支，深度为 $\log_{3/2}n$。因此

$$T(n)=n\cdot\log_{3/2}n=\Theta(n\log n)$$

::: tip 递归树法的三个步骤
1. 画出前两三层，标出每层代价；
2. 找出**每层代价的规律**与**树的深度**；
3. 把“每层代价 × 层数”加起来，注意最后一层可能不满。

递归树尤其适合处理“子问题规模不相等”的递推，这是主定理覆盖不到的情形。
:::

## 2.3.5 分析中的常见陷阱

1. **基本操作选错**。若把 `for` 循环的判断也算作基本操作，系数会变，但阶不变；真正致命的是漏掉内层循环。
2. **忽略提前返回**。带 `return` 的循环，最坏与最好可能相差一个数量级。
3. **把递归调用次数当成时间复杂度**。递归调用次数是 $a^k$，但每层还有合并代价 $f(n)$，必须一起算。
4. **递推式写错初始条件**。$T(1)=O(1)$ 与 $T(0)=O(1)$ 会影响低阶项，但通常不影响阶。
5. **循环边界含变量**。`for j ← i to n` 与 `for j ← 1 to n` 的求和结果不同，务必写出求和上下限。
