# 9.3 参数、收敛性与改进

## 9.3.1 四个基本参数

| 参数 | 含义 | 常用范围（Schaffer 建议） |
| :--- | :--- | :--- |
| $M$ | 种群规模 | $20\sim100$ |
| $T$ | 终止进化代数 | $100\sim500$ |
| $P_c$ | 交叉概率 | $0.4\sim0.9$ |
| $P_m$ | 变异概率 | $0.001\sim0.01$ |

这些范围只是经验值，具体问题需要调参。参数之间相互影响，不能孤立地看。

## 9.3.2 参数对收敛性的影响

### 种群规模 $M$

- **太小**：不能提供足够的采样点，种群多样性不足，容易早熟，算法性能很差；
- **太大**：可以增加优化信息、阻止早熟收敛，但计算量增加，收敛速度变慢。

### 交叉概率 $P_c$

- **太大**：种群中个体更新很快，高适应度个体很快被破坏，优良模式难以积累；
- **太小**：交叉操作很少进行，搜索停滞不前，算法不收敛。

### 变异概率 $P_m$

- **太大**：退化为随机搜索，破坏优良基因；
- **太小**：难以引入新基因，容易陷入局部最优。

### 终止代数 $T$

- **太小**：尚未收敛就停止，解的质量差；
- **太大**：浪费计算资源，后期改进很小。

| 参数 | 增大时 | 减小时 |
| :--- | :--- | :--- |
| $M$ | 多样性好、计算慢 | 计算快、易早熟 |
| $P_c$ | 探索强、易破坏优良个体 | 稳定、易停滞 |
| $P_m$ | 多样性好、近似随机搜索 | 稳定、易局部最优 |
| $T$ | 解质量高、耗时长 | 耗时短、可能未收敛 |

::: tip 调参的基本策略
1. 先用经验范围跑通，观察适应度曲线；
2. 若早期收敛太快（曲线很快变平且解不好），增大 $M$ 或 $P_m$，降低选择压力；
3. 若曲线长期不上升，增大 $P_c$ 或 $P_m$；
4. 若后期震荡，减小 $P_m$，加入精英保留；
5. 用多组参数、多次运行取平均，避免偶然性。
:::

## 9.3.3 收敛性分析

遗传算法要实现**全局收敛**，需要满足两个条件：

1. 任意初始种群经过有限步都能到达全局最优解；
2. 算法必须有**保优操作**，防止最优解在进化中丢失。

与收敛性有关的因素主要包括：种群规模、选择操作、交叉概率、变异概率。

### 种群收敛 vs 全局收敛

- **种群收敛**：种群中所有个体趋于相同（或适应度趋于一致）。这只说明多样性消失，不代表找到了全局最优；
- **全局收敛**：算法以概率 $1$ 找到全局最优解。这需要理论保证（如精英保留 + 正变异概率 + 有限状态马尔可夫链分析）。

::: warning 种群收敛 ≠ 找到最优
若种群过早收敛到一个局部最优，所有个体都一样，交叉不再产生新解，变异概率又很小，算法就“卡死”了。这就是**早熟收敛（premature convergence）**。
:::

### 早熟收敛的原因与对策

| 原因 | 表现 | 对策 |
| :--- | :--- | :--- |
| 选择压力过大 | 超级个体迅速占据种群 | 排序选择、锦标赛、适应度缩放 |
| 种群太小 | 多样性不足 | 增大 $M$ |
| 变异概率太低 | 无法跳出局部最优 | 增大 $P_m$、自适应变异 |
| 交叉破坏优良模式 | 解质量波动大 | 精英保留、降低 $P_c$ |
| 编码/算子不合适 | 有效解难生成 | 换编码、设计专用算子、修复 |

## 9.3.4 改进的遗传算法

### 混合遗传算法

把 GA 与局部搜索结合：GA 负责全局探索，局部搜索负责精细开发。

- **GA + 模拟退火**：用 SA 的接受准则增强局部搜索；
- **Memetic Algorithm**：每个个体交叉/变异后，做一次局部优化（如爬山、2-opt）；
- **GA + 贪心**：用贪心解初始化种群，或对子代做贪心修复。

```mermaid

  A["GA 全局搜索"] --> B["局部搜索（2-opt/爬山）"]
  B --> C["更新种群"]
  C --> A
```

### 免疫遗传算法

借鉴免疫系统的“抗体多样性”和“记忆”机制：

- 把个体看作抗体，适应度高的抗体被保留；
- 用“浓度”控制相似个体，避免种群单一；
- 引入“疫苗”注入先验知识，加速收敛。

### 小生境遗传算法

把种群分成若干小生境，每个小生境内部进化，保持多个不同的局部最优。常用**适应度共享**：相似个体共享适应度，降低拥挤区域的个体优势。

### 单亲遗传算法

不进行交叉，只通过单个个体的变异（如交换、逆转、插入）产生新个体。适合排列编码问题，避免交叉产生非法解。

### 并行遗传算法

- **岛屿模型**：多个子种群独立进化，定期迁移个体；
- **细胞模型**：个体在网格上，只与邻居交叉；
- **适应度并行**：并行计算个体适应度（适合昂贵的目标函数）。

### 自适应参数

让 $P_c$、$P_m$ 随个体适应度或种群多样性动态调整：

- 适应度高于平均的个体，降低 $P_m$，保护优良基因；
- 适应度低于平均的个体，提高 $P_m$，促进探索；
- 种群多样性低时，增大 $P_m$。

## 9.3.5 遗传算法的应用

| 领域 | 典型问题 |
| :--- | :--- |
| 函数优化 | 多峰函数、非线性规划、约束优化 |
| 组合优化 | TSP、背包、调度、装箱、图着色 |
| 生产调度 | 车间调度、流水线调度、任务分配 |
| 自动控制 | 控制器参数整定、模糊规则学习、神经网络结构优化 |
| 机器学习 | 特征选择、超参数搜索、神经网络权重训练 |
| 图像处理 | 图像分割、图像恢复、特征提取 |
| 工程设计 | 结构优化、电路设计、路径规划 |

::: info 遗传算法在调度中的应用
生产调度问题在很多情况下建立的数学模型难以精确求解，即使简化后可以求解，也可能因简化太多而偏离实际。现实中很多调度靠经验进行。遗传算法已成为解决复杂调度问题的有效工具，在单件生产车间调度、流水线车间调度、生产规划、任务分配等方面都有应用。
:::

## 9.3.6 遗传算法的局限与注意事项

1. **无最优性保证**：GA 是随机搜索，不能保证找到全局最优；
2. **参数敏感**：不同参数、不同随机种子，结果可能差异很大；
3. **计算量大**：需要成千上万次适应度评价，目标函数昂贵时难以承受；
4. **早熟收敛**：多样性丢失后停滞；
5. **编码与算子设计依赖经验**：排列、约束问题需要专门设计；
6. **结果解释性弱**：不如精确算法那样能给出最优性证明。

::: warning 不要滥用遗传算法
如果问题有多项式精确算法（如最短路、MST、线性规划），优先用精确算法；如果问题规模小，分支限界可能更快；只有当问题规模大、结构复杂、无有效精确算法时，GA 才是合理选择。
:::
