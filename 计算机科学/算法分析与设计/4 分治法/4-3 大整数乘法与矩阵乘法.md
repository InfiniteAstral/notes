# 4.3 大整数乘法与矩阵乘法

分治法最精彩的应用，往往不是“把问题拆小”，而是**通过代数变换减少子问题的个数**。大整数乘法与矩阵乘法是这一思想的两个里程碑。

## 4.3.1 大整数乘法

问题：设 $X$ 和 $Y$ 都是 $n$ 位二进制数，设计一个有效算法计算它们的乘积 $XY$。

### 朴素做法

按位相乘再累加，需要做 $n^2$ 次一位乘法，时间复杂度 $O(n^2)$。当 $n$ 达到数十万位（如密码学中的大整数）时，这个代价无法接受。

### 分治：把数拆成两半

把 $X,Y$ 各分成高位和低位两半（设 $n$ 为偶数）：

$$X=A\cdot 2^{n/2}+B,\qquad Y=C\cdot 2^{n/2}+D$$

其中 $A,B,C,D$ 都是 $n/2$ 位的数。于是

$$XY=AC\cdot 2^{n}+(AD+BC)\cdot 2^{n/2}+BD$$

这样，一个 $n$ 位乘法被转化为 **4 个 $n/2$ 位乘法**（$AC,AD,BC,BD$）以及若干次移位和加法。移位就是乘 $2$ 的幂，在二进制下只是左移，代价 $O(n)$。

$$T(n)=4T\left(\frac{n}{2}\right)+O(n)$$

由主定理，$a=4,b=2$，$\log_2 4=2$，$f(n)=O(n)$ 小于 $n^2$，故

$$T(n)=\Theta(n^2)$$

**没有改进**——只是把竖式乘法换了一种写法。

### 改进：三次乘法

关键在于 $AD+BC$ 不必分别计算。注意到

$$(A-B)(D-C)=AD-AC-BD+BC$$

移项得

$$AD+BC=(A-B)(D-C)+AC+BD$$

于是只需计算三个乘积：

$$P_1=AC,\qquad P_2=BD,\qquad P_3=(A-B)(D-C)$$

则

$$XY=P_1\cdot 2^n+(P_3+P_1+P_2)\cdot 2^{n/2}+P_2$$

递推式变为

$$T(n)=3T\left(\frac{n}{2}\right)+O(n)$$

由主定理，$\log_2 3\approx1.585$，故

$$T(n)=\Theta\left(n^{\log_2 3}\right)=O\left(n^{1.585}\right)$$

这是一个**实质性的改进**：$n$ 翻倍时，工作量只增加到约 $3$ 倍，而不是 $4$ 倍。

```text
multiply(X, Y, n)
// 输入：两个 n 位二进制数 X, Y（n 为 2 的幂）
// 输出：X * Y
if n = 1 return X * Y
A ← X div 2^(n/2);  B ← X mod 2^(n/2)
C ← Y div 2^(n/2);  D ← Y mod 2^(n/2)
P1 ← multiply(A, C, n/2)
P2 ← multiply(B, D, n/2)
P3 ← multiply(A - B, D - C, n/2)
return P1 * 2^n + (P3 + P1 + P2) * 2^(n/2) + P2
```

::: warning 减法会产生负数
$A-B$ 或 $D-C$ 可能为负，递归时需按有符号数处理，或在调用前统一加上偏移量。工程实现中通常直接使用带符号的大整数类型，避免额外判断。
:::

### 进一步优化

- 把整数分成更多段（如 3 段），用更复杂的组合方式，可得到更低的指数；
- 这一思想最终导向**快速傅里叶变换（FFT）**：把多项式乘法转化为点值乘法，时间复杂度 $O(n\log n)$，是现代大整数乘法（如 Schönhage–Strassen 算法）的基础；
- 实际库（Java `BigInteger`、Python 大整数）会在不同规模下切换 Karatsuba、Toom-Cook、FFT 等算法。

::: info Karatsuba 算法
上述“三次乘法”的算法由 Karatsuba 于 1960 年提出，是第一个突破 $O(n^2)$ 的整数乘法算法。它的意义不仅在于快，更在于证明了**“看起来必须做四次乘法”的问题，可以通过代数恒等式减少到三次**。
:::

## 4.3.2 矩阵乘法

问题：计算两个 $n$ 阶方阵的乘积 $C=A\times B$，其中

$$C[i][j]=\sum_{k=0}^{n-1}A[i][k]\,B[k][j]$$

### 朴素算法

每个 $C[i][j]$ 需要 $n$ 次乘法和 $n-1$ 次加法，共有 $n^2$ 个元素，故

$$T(n)=O(n^3)$$

三重循环，空间 $O(n^2)$。

### 分治：分块矩阵

把 $A,B,C$ 各分成四个 $n/2$ 阶的子矩阵：

$$\begin{bmatrix}C_{11}&C_{12}\\C_{21}&C_{22}\end{bmatrix}
=\begin{bmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{bmatrix}
\begin{bmatrix}B_{11}&B_{12}\\B_{21}&B_{22}\end{bmatrix}$$

展开得

$$\begin{aligned}
C_{11}&=A_{11}B_{11}+A_{12}B_{21}\\
C_{12}&=A_{11}B_{12}+A_{12}B_{22}\\
C_{21}&=A_{21}B_{11}+A_{22}B_{21}\\
C_{22}&=A_{21}B_{12}+A_{22}B_{22}
\end{aligned}$$

共需 **8 个 $n/2$ 阶矩阵乘法**和 4 次矩阵加法。加法代价 $O(n^2)$，因此

$$T(n)=8T\left(\frac{n}{2}\right)+O(n^2)$$

由主定理，$\log_2 8=3$，$f(n)=O(n^2)$ 小于 $n^3$，故

$$T(n)=\Theta(n^3)$$

同样没有改进。

### Strassen 算法：七次乘法

Strassen 在 1969 年发现，可以用 **7 次**子矩阵乘法完成计算。定义：

$$\begin{aligned}
M_1&=A_{11}(B_{12}-B_{22})\\
M_2&=(A_{11}+A_{12})B_{22}\\
M_3&=(A_{21}+A_{22})B_{11}\\
M_4&=A_{22}(B_{21}-B_{11})\\
M_5&=(A_{11}+A_{22})(B_{11}+B_{22})\\
M_6&=(A_{12}-A_{22})(B_{21}+B_{22})\\
M_7&=(A_{11}-A_{21})(B_{11}+B_{12})
\end{aligned}$$

则

$$\begin{aligned}
C_{11}&=M_5+M_4-M_2+M_6\\
C_{12}&=M_1+M_2\\
C_{21}&=M_3+M_4\\
C_{22}&=M_5+M_1-M_3-M_7
\end{aligned}$$

一共 **7 次乘法**、18 次加减法。递推式变为

$$T(n)=7T\left(\frac{n}{2}\right)+O(n^2)$$

由主定理，

$$T(n)=\Theta\left(n^{\log_2 7}\right)\approx O\left(n^{2.807}\right)$$

| 算法 | 乘法次数 | 时间复杂度 | 实用规模 |
| :--- | :--- | :--- | :--- |
| 朴素三重循环 | $n^3$ | $O(n^3)$ | 小矩阵，常数最小 |
| 分块（8 次乘法） | $8^k$ | $O(n^3)$ | 理论演示 |
| Strassen（7 次乘法） | $7^k$ | $O(n^{2.807})$ | 大规模稠密矩阵 |

::: warning Strassen 并非总是更快
Strassen 的常数因子和额外空间开销较大，且数值稳定性不如朴素算法。实际库通常只在 $n$ 超过某个阈值（如 $n>1000$）时才启用，小矩阵仍用朴素算法或高度优化的 BLAS。
:::

### 还能更快吗？

- Hopcroft 和 Kerr 已证明：计算两个 $2\times2$ 矩阵的乘积，**7 次乘法是必要的**。因此想进一步改进，不能再基于 $2\times2$ 分块。
- 此后出现了一系列改进算法，课件给出的上界是 $O(n^{2.376})$；后续研究进一步降低到约 $O(n^{2.371552})$（2024 年）。
- 目前已知的**下界仍是 $\Omega(n^2)$**：至少要读一遍输入、写一遍输出。能否达到 $O(n^2)$，仍是开放问题。

::: info 深度学习中的矩阵乘法
Transformer 中的注意力矩阵计算、卷积展开后的 GEMM、大模型推理的 KV Cache 更新，本质上都是大规模矩阵乘法。工程上的优化手段包括：**分块（tiling）提高缓存命中率**、**Strassen/低秩近似减少乘法**、**GPU Tensor Core 的专用指令**、**稀疏化与量化**。算法课上的 $O(n^3)\to O(n^{2.807})$ 是理论基础，真实的加速往往来自存储层次与并行。
:::
