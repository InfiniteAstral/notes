# 8.5 货郎担、批作业调度、布线与最大团

## 8.5.1 货郎担问题（TSP）

### 问题回顾

给定 $n$ 个城市及两两之间的距离矩阵 $C$，求一条从某城市出发、经过每个城市恰好一次、最后回到起点的最短回路。

解空间是排列树，叶子数 $(n-1)!$。分支限界法的关键是设计一个**可计算的下界**。

### 下界一：两条最小边之和

任何一条哈密顿回路中，每个城市恰好有两条边相连。因此，对每个城市 $v$，回路中与 $v$ 相连的两条边，其长度之和至少是 $v$ 的所有关联边中最小的两条之和。于是

$$LB=\frac{1}{2}\sum_{v\in V}\bigl(d_1(v)+d_2(v)\bigr)$$

其中 $d_1(v),d_2(v)$ 是 $v$ 的两条最小关联边。除以 $2$ 是因为每条边被两个端点各算了一次。结果向上取整。

对部分解，已选的边必须计入，且每个顶点最多连两条边；可以在这个约束下重新计算“最小两条边”，得到更紧的下界。

### 下界二：矩阵归约

这是更常用的方法（Little 算法）。以课件中的 5 城市矩阵为例：

$$C=\begin{bmatrix}
\infty & 3 & 1 & 5 & 8\\
3 & \infty & 6 & 7 & 9\\
1 & 6 & \infty & 4 & 2\\
5 & 7 & 4 & \infty & 3\\
8 & 9 & 2 & 3 & \infty
\end{bmatrix}$$

**第一步：行归约**。每行减去该行最小值：

| 行 | 最小值 |
| :--- | ---: |
| 1 | 1 |
| 2 | 3 |
| 3 | 1 |
| 4 | 3 |
| 5 | 2 |

行归约总和 $=1+3+1+3+2=10$。归约后的矩阵：

$$\begin{bmatrix}
\infty & 2 & 0 & 4 & 7\\
0 & \infty & 3 & 4 & 6\\
0 & 5 & \infty & 3 & 1\\
2 & 4 & 1 & \infty & 0\\
6 & 7 & 0 & 1 & \infty
\end{bmatrix}$$

**第二步：列归约**。每列减去该列最小值（第 1 列 $0$、第 2 列 $2$、第 3 列 $0$、第 4 列 $1$、第 5 列 $0$），总和 $=3$。归约后的矩阵：

$$\begin{bmatrix}
\infty & 0 & 0 & 3 & 7\\
0 & \infty & 3 & 3 & 6\\
0 & 3 & \infty & 2 & 1\\
2 & 2 & 1 & \infty & 0\\
6 & 5 & 0 & 0 & \infty
\end{bmatrix}$$

**根结点的下界**：

$$LB=10+3=13$$

**上界**：用贪心构造一条回路，例如 $1\to3\to5\to4\to2\to1$，长度为

$$1+2+3+7+3=16$$

故 $UB=16$（作为初始 `best`）。

### 分支与更新

从根结点出发，对“从城市 1 出发到哪个城市”分支。若选择边 $(1,3)$：

1. 把第 1 行、第 3 列置为 $\infty$（离开 1、进入 3 的边不能再选）；
2. 把 $(3,1)$ 置为 $\infty$（避免提前形成子回路）；
3. 对剩余矩阵重新行/列归约，新增的归约量加到当前 $LB$ 上。

用优先队列按 $LB$ 从小到大扩展。若某结点的 $LB\ge best$，剪枝；当队列中取出的结点形成完整回路时，即得最优解。

::: tip 为什么矩阵归约是下界？
每次行/列归约减去的量，是“无论怎么选都至少要支付”的代价：一行中必须选一条边离开，其长度至少是该行最小值；一列中必须选一条边进入，其长度至少是该列最小值。把所有必付的最小量加起来，自然不超过任何完整回路的长度。
:::

## 8.5.2 批作业调度问题

### 问题回顾

$n$ 个作业，每个作业先在 $M_1$ 上加工 $t_{1i}$，再在 $M_2$ 上加工 $t_{2i}$。求加工顺序，使所有作业在 $M_2$ 上的完成时间之和最小。

解空间是排列树。分支限界法的结点需要保存：

| 字段 | 含义 |
| :--- | :--- |
| `level` | 已安排的作业数 |
| `x[]` | 当前加工顺序 |
| `f1` | $M_1$ 上最后一个作业的完成时间 |
| `f2` | $M_2$ 上最后一个作业的完成时间 |
| `sf2` | 当前所有作业在 $M_2$ 上的完成时间之和 |
| `lb` | 完成时间和的下界 |

### 下界

已安排部分的完成时间和为 `sf2`。对剩余 $m=n-\text{level}$ 个作业，估计一个“理想”的额外完成时间和：

- 假设 $M_1$ 无空闲，剩余作业按 $t_1$ **升序**紧凑加工——短作业放前面，让大系数配小值，得到 $M_1$ 完成时间和的最小可能值；
- 每个作业在 $M_2$ 上至少还要花 $t_{2i}$，因此再加上 $\sum t_{2i}$；
- 也可对 $M_2$ 做类似的升序估计，取更紧的那个。

一个简单而有效的下界是

$$LB=sf2+\sum_{k=1}^{m}(m-k+1)\,t_{1,\text{sorted}}[k]+\sum_{k=1}^{m}t_{2}[k]$$

其中 $t_{1,\text{sorted}}$ 是剩余作业的 $t_1$ 升序排列。

```java
int bound(Node u, int n, int[] t1, int[] t2) {
    int m = n - u.level;
    int[] a = new int[m];
    for (int k = 0; k < m; k++) a[k] = t1[u.x[u.level + k + 1]];
    Arrays.sort(a);
    int lb = u.sf2;
    for (int k = 0; k < m; k++) lb += (m - k) * a[k];
    for (int k = u.level + 1; k <= n; k++) lb += t2[u.x[k]];
    return lb;
}
```

### 优先队列式搜索

按 `lb` 从小到大扩展。每次从堆中取出 `lb` 最小的结点，生成所有儿子：

- 对每个儿子，交换作业位置，计算新的 `f1`、`f2`、`sf2` 和 `lb`；
- 若 `lb < bestc`，加入堆；否则剪枝；
- 当取出的结点 `level == n` 时，得到一个完整调度，更新 `bestc`。

::: info 与回溯法的对比
批作业调度的回溯法（7.3 节）用 `sf2 < bestc` 剪枝，深度优先；分支限界法用更精细的 `lb`（包含剩余作业的乐观估计），并按 `lb` 从小到大扩展，通常能更早找到好解、剪掉更多分支。代价是需要为每个结点计算 `lb`，并维护一个可能很大的堆。
:::

## 8.5.3 布线问题

### 问题

在一块 $m\times n$ 的网格板上，有一些方格被占用（障碍）。给定起点 $a$ 和终点 $b$，求一条从 $a$ 到 $b$ 的最短路径，路径只能沿上下左右移动，不能穿过障碍。

这是无权图上的最短路问题，用 **BFS（广度优先搜索）** 即可，本质上就是 FIFO 队列式分支限界：

- 从起点开始，把相邻且未访问的方格标记为“距离 1”，加入队列；
- 每次从队首取出一个方格，把它相邻且未访问的方格标记为“当前距离 + 1”，加入队列；
- 当访问到终点时停止。

```java
boolean findPath(int[][] grid, Position start, Position finish, int m, int n) {
    if (start.equals(finish)) return true;
    Queue<Position> q = new LinkedList<>();
    Position[] offset = { new Position(0,1), new Position(1,0),
                          new Position(0,-1), new Position(-1,0) };
    grid[start.row][start.col] = 1;     // 起点标记为 1
    q.add(start);

    while (!q.isEmpty()) {
        Position here = q.poll();
        for (Position d : offset) {
            Position nbr = new Position(here.row + d.row, here.col + d.col);
            if (nbr.row < 0 || nbr.row >= m || nbr.col < 0 || nbr.col >= n) continue;
            if (grid[nbr.row][nbr.col] != 0) continue;   // 障碍或已访问
            grid[nbr.row][nbr.col] = grid[here.row][here.col] + 1;
            if (nbr.equals(finish)) return true;
            q.add(nbr);
        }
    }
    return false;
}
```

### 复杂度

每个方格最多入队一次，时间 $O(mn)$，空间 $O(mn)$。

::: tip 为什么 BFS 能得到最短路径？
BFS 按“距离起点的步数”分层扩展：先访问距离 1 的所有方格，再距离 2 的……第一次到达终点时，经过的步数一定最少。这与分支限界法“按层扩展”的思想完全一致，只是这里没有显式的界函数。

布线问题还可以用于游戏中的寻路（如网格地图的最短路径）、PCB 布线、机器人路径规划。
:::

## 8.5.4 最大团问题

### 问题回顾

给定无向图 $G=(V,E)$，求顶点数最多的团（两两相邻的顶点子集）。解空间是子集树。

### 上界

设当前已选团大小为 `cn`，正在决定第 $i$ 个顶点，剩余可选顶点为 $i,i+1,\dots,n$，共 $n-i+1$ 个。即使把剩余全部选入，团大小也不超过

$$UB=cn+(n-i+1)$$

若 $UB\le bestn$，当前分支不可能产生更大的团，剪枝。

### 结点与算法

```java
class Node {
    int upperSize;    // 团大小上界
    int level;        // 层
    Node parent;
    boolean leftChild;
}
```

优先队列按 `upperSize` 从大到小：

```java
int maxCliqueBB(boolean[][] a, int n) {
    PriorityQueue<Node> heap = new PriorityQueue<>(
        (x, y) -> y.upperSize - x.upperSize);
    Node root = new Node();
    root.upperSize = n;
    root.level = 1;
    heap.add(root);

    int bestn = 0, cn = 0, i = 1;
    Node current = null, bestNode = null;
    boolean[] in = new boolean[n + 1];   // 当前路径上被选中的顶点

    while (i != n + 1) {
        restore(current, in);            // 先恢复当前结点的路径
        // 左儿子：选顶点 i（需与前团全相邻）
        if (ok(i, in)) {
            if (cn + 1 > bestn) {
                bestn = cn + 1;
                bestNode = new Node(cn + 1 + n - i, i + 1, current, true);
            }
            heap.add(new Node(cn + 1 + n - i, i + 1, current, true));
        }
        // 右儿子：不选
        if (cn + n - i > bestn) {
            heap.add(new Node(cn + n - i, i + 1, current, false));
        }
        if (heap.isEmpty()) break;
        current = heap.poll();
        i = current.level;
        cn = current.upperSize - (n - i + 1);
    }
    return bestn;
}

void restore(Node u, boolean[] in) {
    Arrays.fill(in, false);
    while (u != null) {
        if (u.leftChild) in[u.level - 1] = true;
        u = u.parent;
    }
}

boolean ok(int i, boolean[] in) {
    for (int j = 1; j < i; j++)
        if (in[j] && !a[i][j]) return false;
    return true;
}
```

::: warning 优先队列必须能恢复路径
回溯法的路径隐含在递归栈里，天然可用；分支限界法在结点之间跳转，**全局的 `x[]` 并不对应当前结点**。因此要么像上面这样沿 `parent` 指针恢复路径，要么在每个结点里直接保存一个位向量。否则 `ok(i)` 会检查错误的“当前团”。
:::

::: tip 第一个叶子就是最大团
优先队列按上界从大到小扩展。当某个叶子（$i=n+1$）被取出时，它的上界等于实际团大小；队列中其余结点的上界都不超过它，因此不可能有更大的团。故第一个叶子对应最大团。
:::

## 8.5.5 四个问题的对比

| 问题 | 解空间树 | 界 | 搜索策略 | 最坏复杂度 |
| :--- | :--- | :--- | :--- | :--- |
| 货郎担 | 排列树 | 矩阵归约 / 两最小边 | 优先队列（$LB$ 小优先） | $O(n!)$ |
| 批作业调度 | 排列树 | 完成时间和的理想估计 | 优先队列（$LB$ 小优先） | $O(n!)$ |
| 布线 | 网格图 | 无（BFS 分层） | FIFO 队列 | $O(mn)$ |
| 最大团 | 子集树 | $cn+n-i+1$ | 优先队列（$UB$ 大优先） | $O(2^n)$ |

::: info 布线问题为什么放在分支限界一章？
布线问题没有显式的“上界/下界”，但它的 BFS 过程就是 FIFO 队列式分支限界的特例：活结点是待扩展的方格，扩展时生成四个邻居，用“是否已访问/是否障碍”作为约束剪枝。它帮助我们理解“分支限界法不一定非要有复杂的界函数”。
:::

## 8.5.6 问题思考

### 如何给出一个好的下界？

- **松弛约束**：TSP 中允许重复访问 → 最小生成树；允许不连通 → 两最小边；允许小数 → 分数背包。
- **理想化调度**：批作业中假设机器无空闲、短作业优先。
- **组合多个松弛**：取多个有效下界中的**最大值**，得到更紧的界。
- **利用已选部分**：把已确定的边/作业计入，剩余部分再用松弛估计。

### 如何判断界值设计的好坏？

- 随机生成大量实例，统计算法运行时间与扩展结点数；
- 与理论最优值（小规模用蛮力求得）比较，计算界的平均差距；
- 观察“剪枝率”：被剪结点数 / 总生成结点数。

### 有多个上界或下界怎么用？

- 极大化问题：$UB=\min\{UB_1,UB_2,\dots\}$（越小越紧），$LB=\max\{LB_1,LB_2,\dots\}$（越大越好）；
- 极小化问题：$LB=\max\{LB_1,LB_2,\dots\}$（越大越紧），$UB=\min\{UB_1,UB_2,\dots\}$（越小越好）。

前提是每个界都**单独有效**；若某个界不合法，取 min/max 后可能把最优解剪掉。

### 回溯法不用太考虑界，分支限界必须认真设计界，对吗？

基本正确，但不绝对：

- 回溯法求“所有解”时，只需要约束函数，界函数可以不用；求“最优解”时，界函数同样重要，只是它藏在深度优先的递归里。
- 分支限界法几乎总是求最优解，界的质量直接决定它是否比穷举快，因此必须认真设计。

### 两种方法分别什么时候用？

| 需求 | 推荐 |
| :--- | :--- |
| 列出所有解 | 回溯法 |
| 找一个可行解 | 回溯法（约束强时） |
| 求最优解，界紧 | 分支限界法（优先队列） |
| 内存很小 | 回溯法 |
| 解空间树很宽 | 分支限界法 + 强界 |

::: warning 避免“分支限界法一定更快”的误解
分支限界法需要为每个结点计算界、维护活结点表，单结点开销和空间都更大。若界很松，它可能比回溯法更慢、更占内存。选择方法时，要看**界是否容易计算且足够紧**，而不是看名字。
:::

## 8.5.7 本章总结

分支限界法适用于求解**组合搜索问题（含组合优化问题）**：

- **求解条件**：满足多米诺性质；
- **解的表示**：子集树或排列树；
- **分支条件**：约束条件或界条件；
- **分支策略**：FIFO 队列、优先队列；
- **降低时间复杂性的主要途径**：利用界函数对搜索树剪枝，**难点在于界的设计**。

::: tip 考试答题模板
1. 定义解向量与解空间树；
2. 写出约束函数与界函数（极大化写 $UB$，极小化写 $LB$）；
3. 说明搜索策略（FIFO/优先队列）与结点结构；
4. 画出前几层搜索树，标出每个结点的界与剪枝原因；
5. 分析最坏复杂度与空间；
6. 说明如何构造最优解（父指针回溯）。
:::
