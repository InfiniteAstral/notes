# 8.3 装载问题

## 8.3.1 问题与转化

有 $n$ 个集装箱要装上两艘载重量分别为 $c_1$、$c_2$ 的轮船，第 $i$ 个集装箱重量为 $w_i$，且 $\sum w_i\le c_1+c_2$。

若问题有解，一定可以按“先把第一艘船尽可能装满，再把剩余装上第二艘船”的方式装载。因此只需解决：

> 选取一个子集，使重量之和不超过 $c_1$，且尽可能大。

这是特殊的 0-1 背包：每件物品的价值等于重量。解空间是一棵**子集树**。

## 8.3.2 FIFO 队列式：简化版本

教材先给出一个最朴素的队列式实现：

```java
int maxLoadingFIFO(int[] w, int c, int n) {
    Queue<Integer> q = new LinkedList<>();
    q.add(-1);                    // 层结束标记
    int i = 1, cw = 0, bestw = 0;
    while (!q.isEmpty()) {
        if (cw + w[i] <= c) addLiveNode(q, cw + w[i], i + 1);  // 左儿子
        addLiveNode(q, cw, i + 1);                              // 右儿子
        cw = q.poll();
        if (cw == -1) {           // 一层结束
            if (q.isEmpty()) return bestw;
            q.add(-1);
            cw = q.poll();
            i++;                  // 进入下一层
        }
    }
    return bestw;
}
```

这个版本有三个明显问题：

1. **没有保存路径**：只返回最大载重量，给不出具体装载方案；
2. **没有界剪枝**：左右儿子都无条件加入，属于盲目搜索；
3. **更新太晚**：直到叶子（$i=n+1$）才更新 `bestw`，而实际上在生成左儿子时就可以更新。

## 8.3.3 FIFO 改进版：父指针 + 提前更新 + 界剪枝

### 结点结构

```java
class QNode {
    int cw;              // 当前载重量
    QNode parent;        // 父结点
    boolean leftChild;   // 是否为左儿子（装入）
}
```

用 `parent` 和 `leftChild` 可以在找到最优解后回溯出装载方案。

### 关键改进

- **提前更新**：生成左儿子（装入第 $i$ 个）时，若 `cw + w[i] > bestw`，立即更新 `bestw` 并记录 `bestNode`；
- **界剪枝**：右儿子（不装）只有在 `cw + r > bestw` 时才加入队列，其中 `r` 是剩余集装箱总重量；
- **层标记**：用 `cw = -1` 的哑结点标记一层结束，同时更新 `r`。

```java
while (!q.isEmpty()) {
    // 左儿子：装入
    if (cw + w[i] <= c) {
        if (cw + w[i] > bestw) {
            bestw = cw + w[i];
            bestNode = new QNode(bestw, current, true);
        }
        addLiveNode(q, cw + w[i], current, true, i + 1);
    }
    // 右儿子：不装，用上界剪枝
    if (cw + r > bestw) {
        addLiveNode(q, cw, current, false, i + 1);
    }
    // 取下一个扩展结点
    current = q.poll();
    cw = current.cw;
    if (cw == -1) {              // 一层结束
        if (q.isEmpty()) break;
        q.add(new QNode(-1, null, false));
        current = q.poll();
        cw = current.cw;
        i++;
        r -= w[i];               // 进入下一层，剩余重量减少
    }
}
```

::: warning 层标记结点的 `cw = -1`
`-1` 是哑值，不会与真实载重量混淆（真实载重量非负）。每次遇到 `-1`，说明上一层的所有结点都已扩展完，层数加一，剩余重量 `r` 减去当前物品的重量。
:::

### 复杂度

最坏 $O(2^n)$ 个结点，每个结点 $O(1)$ 处理，时间 $O(2^n)$；队列最多存 $O(2^n)$ 个结点，空间 $O(2^n)$。

## 8.3.4 优先队列式：按上界扩展

### 上界的设计

对结点 $v$（已决定前 $i-1$ 件，当前载重 `cw`），剩余物品 $i..n$ 的总重量为

$$r[i]=\sum_{k=i}^{n}w_k$$

从 $v$ 出发，最多还能装 $r[i]$，因此

$$UB(v)=cw+r[i]$$

这是“把剩余全部装上”的乐观上界。

### 结点结构

```java
class Node {
    int uweight;     // 上界 = cw + r[level]
    int level;       // 所在层
    Node parent;
    boolean leftChild;
}
```

优先队列按 `uweight` **从大到小**排序（最大堆）。

### 算法

```java
int maxLoadingPrior(int[] w, int c, int n) {
    int[] r = new int[n + 2];
    for (int j = n; j > 0; j--) r[j] = r[j + 1] + w[j];

    PriorityQueue<Node> heap = new PriorityQueue<>(
        (a, b) -> b.uweight - a.uweight);
    Node current = null;
    int i = 1, cw = 0, bestw = 0;
    Node bestNode = null;

    while (i != n + 1) {
        // 左儿子
        if (cw + w[i] <= c) {
            if (cw + w[i] > bestw) {
                bestw = cw + w[i];
                bestNode = new Node(cw + w[i] + r[i + 1], i + 1, current, true);
            }
            heap.add(new Node(cw + w[i] + r[i + 1], i + 1, current, true));
        }
        // 右儿子
        if (cw + r[i + 1] > bestw) {
            heap.add(new Node(cw + r[i + 1], i + 1, current, false));
        }
        if (heap.isEmpty()) break;
        current = heap.poll();
        i = current.level;
        cw = current.uweight - r[i];   // 还原当前载重
    }
    // 沿 bestNode.parent 回溯得到方案
    return bestw;
}
```

### 为什么第一个叶子就是最优？

优先队列按 $UB$ 降序。当某个叶子被取出时，它的 $UB$ 等于它的实际载重量；队列中其他结点的 $UB$ 都不超过它，因此不可能产生更大的载重量。故第一个叶子即最优解。

::: tip `cw = uweight - r[i]` 的由来
结点只存了 $UB=cw+r[i]$，没有直接存 `cw`。取出结点后，用 $UB$ 减去当前层的剩余重量 $r[i]$，就还原出 `cw`。这样每个结点少存一个字段，空间更省。
:::

## 8.3.5 一个例子

设 $W=\langle90,80,40,30,20,12,10\rangle$，$c_1=152$，$c_2=130$。

一种最优装载为：第一艘船装 $90+30+20+12=152$，第二艘船装 $80+40+10=130$。

搜索过程中的关键剪枝：

- 根结点 $UB=282$，远大于 $c_1$，但受容量约束，实际只能装到 $152$；
- 当某分支已装 $90+80=170>152$，左儿子直接因容量约束被剪；
- 当某分支的 $UB=cw+r\le bestw$ 时，整棵子树被剪。

优先队列会优先扩展“当前载重 + 剩余全部”最大的结点，尽快接近 $152$，从而让 `bestw` 迅速提高，剪掉更多分支。

::: info 与回溯法的对比
回溯法（7.4 节）用 `cw + r > bestw` 剪枝，深度优先；分支限界法用同样的界，但按 $UB$ 从大到小扩展。对装载问题，两者最坏都是 $O(2^n)$，但分支限界法通常能更早找到好解，平均结点数更少；代价是需要显式存储活结点，空间更大。
:::

## 8.3.6 两种实现方式的对比

| 维度 | FIFO 队列式 | 优先队列式 |
| :--- | :--- | :--- |
| 扩展顺序 | 按层，先进先出 | 按 $UB$ 从大到小 |
| 界 | 可用 $cw+r>bestw$ | 必须计算 $UB$ |
| 第一个叶子 | 不一定最优 | 一定最优 |
| 空间 | 可能存整层结点 | 可能存大量结点 |
| 实现难度 | 较低（层标记） | 较高（堆 + 上界） |
| 适用 | 教学、层序清晰 | 求最优解、希望快速剪枝 |

::: tip 考试要点
1. 能写出装载问题的解向量、约束与界；
2. 能说明为什么“尽量装满第一艘船”是充分的；
3. 能区分 FIFO 的层标记与优先队列的上界；
4. 能根据 $UB=cw+r$ 判断某个结点是否被剪；
5. 能沿父指针回溯出装载方案。
:::
